# TV application workspace

Contains the internal W01 probe UI, remote focus/input, lifecycle and Samsung adapters. The build is a basic unsigned WGT, not the F01–F20 client. Native sockets, actual AVPlay media and protected sessions remain gated by device/toolchain evidence. The preferred product candidate is WGT with on-TV WASM; .NET/TPK remains an alternative gated by W01.
