# F05本机队列与分P播放整合

更新：2026-10-21。内部候选 **0.27.0 / BiliSofa W03** 已自有签名安装启动，所请求A–D USER PASS；实现合同见[ADR-066](adr/066-part-aware-local-queue.md)。本模块为普通视频队列，完整F05类型/权限与W07矩阵仍OPEN；不包含PGC队列或云端写入。

| 能力 | 当前行为 |
| --- | --- |
| 入队 | 普通播放页保存实际当前P；云端历史保留所记录P；稍后再看/收藏未指定P则仍为首P |
| 队列 | BV＋P去重、四卡分页、逐P排序/移除、固定身份64项上限；无网络URL/CID/凭据 |
| 持久化 | 新v2/schema2，缺v2时只读兼容v1首P；显式编辑才写新键，旧键字节保留供回退 |
| 播放/续播 | 当前身份生产源重新解析指定P，读取/保存该P位置；下一项从头；失败/未知关闭停止，不跳P或跳项 |
| 连播/生命周期 | 默认不自动播放；显式开启后自然结束、实际双关闭再推进；Back/Home取消，返回不自动起播 |
| 删除/恢复 | 当前v2损坏/未来格式不回退旧数据；清空/账号移除先确认旧键删除，再删新键，避免旧队列复活 |

## 一次集中验收

仅使用一条你已有的较短、至少两P的普通公开视频；没有样本可直接反馈缺样本，不反复寻找。不清空原有队列、不新增云端内容。

A. 普通播放页将同一视频P1、P2各入队一次，P2再点一次。回本机队列，应有分别标记P1/P2的两个条目且P2不重复；旧条目仍保留。将P2上移至P1前，应保持焦点在该P2。

B. 从队列P2“从本项开始播放”，核对确实是P2与正常声画约10秒，停止并返回；再次开始应出现P2的继续观看，继续后声画/位置正常。随后点“下一项”（若有）应播放队列下一条的正确P，Back停声。

C. 正常退出重开，队列/P号/顺序仍保留且不自动播放。若首P或P2很短，可在开始前开启“播完自动下一项”，自然结束应只推进一次到下一条；没有短样本就标“自然结束未测”，不为此长时间等待。

D. 播放中Home停声，重开队列不自动播放。若云端历史当前正有P2记录，可在其只读摘要加入本机队列并核对P2；无该记录直接跳过，不产生云端写入。

反馈“A/B/C/D实际结果”；失败即停并保留完整错误，不连续重试。只测本队列整合，不重复推荐、投屏、字幕/弹幕、评论、登录或延期直播。真实双账号/完整权限/其他类型及两小时压力不在本组中冒充通过。

验收归档：用户回复“全部测试通过，请继续”，由仓库外`w03-270-user-acceptance.json`配对冻结源码/包。可选短P自然结束及云端历史P2未单独分列，不外推完整矩阵；停止重复本组。
