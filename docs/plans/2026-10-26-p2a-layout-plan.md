# P2a 界面与布局改动方案

2026-10-26。对应[ADR-114](../adr/114-tv-layout-and-visual-pass.md)。状态：**用户已确认（2026-10-26），0.61.0已实现，未装机**；实现细节见ADR-114“实现（0.61.0）”；设备测量后0.61.1关闭模糊背景。分支`perf/p0-network-kernel`，实现后为0.61.0。

## 目标

- 首屏能看到更多内容；
- 卡片与详情页的信息排布更紧凑、留白更合理；
- 加载与失败状态不再显得空或刺眼；
- 焦点有一个属于BiliSofa的辨识点；
- 样式文件收拢成一套变量，不再互相覆盖。

## 改动清单

| 范围 | 文件 | 改动 |
| --- | --- | --- |
| 样式变量 | `apps/tv/public/product-ui.css` | 颜色、字号四档、间距、圆角、焦点集中为变量；合并`.tv-card:focus`、`#overlays>section.tv-detail`等重复定义 |
| 首页标题区 | `apps/tv/src/app/product-home.ts`、`product-page.ts`、CSS | 去掉标语与大标题，改一行身份小字 |
| 卡片 | `apps/tv/src/ui/content-card.ts`、`library-card.ts`、CSS | 标题两行截断，元信息紧贴标题 |
| 货架状态 | `apps/tv/src/app/product-shelves.ts`、CSS | 加载时骨架卡；失败时一行原因加“重试”“查看更多”按钮 |
| 焦点框 | CSS | 卡片焦点加两根“天线”伪元素；减少动画时只去掉放大 |
| 背景氛围 | 新的`apps/tv/src/ui/backdrop.ts`、`product-home.ts`、`product-video-detail.ts`、CSS | 焦点停留约300 ms后，用已加载封面的同一blob地址做模糊暗化背景；可整体关闭 |
| 详情两栏 | `apps/tv/src/app/product-video-detail.ts`、CSS | 左封面，右标题/数据/简介三行/操作；分P一行在下 |
| 播放器 | `apps/tv/src/app/player-presentation.ts`、CSS | 快捷设置条加图标与主行同样式；进度条8/12 px，时间放进度条右端 |
| 搜索 | `apps/tv/src/app/keyword-pad.ts`、CSS | 空候选显示一行提示；“更多候选”改“更多” |
| 测试 | 合成UI新增四条（见ADR-114）；截图脚本 | — |
| 版本与文档 | 版本号、`TV_PRODUCT_DESIGN.md`的视觉规范表 | 0.61.0 |

## 设备验证

- 安装后实看：首页、卡片焦点、详情、播放器、搜索。
- 用Inspector测首页连续方向键（例如连按右键10次）的响应时间，与0.60.1对比，决定是否保留模糊背景。

## 估算

约2.5天：样式收拢与首页1天，详情、播放器、搜索1天，测试、截图对比与装机半天。

## 需要你确认的决定

1. 首页去掉标语与大标题，首屏看到约2.5排；卡片标题两行、元信息紧贴；失败货架只占一行；加载时显示骨架卡？
2. 内容卡片的焦点加“小电视”天线（本次唯一的特色元素），其余界面保持克制？
3. 首页与详情页用已加载封面做模糊暗化背景，设备上若明显变慢就关掉？
4. 详情页改两栏（左封面，右信息与操作，分P在下）？
5. 播放器快捷设置条与主行同样式、进度条加粗并把时间放到右端；搜索空候选与“更多”的细节一并做？
