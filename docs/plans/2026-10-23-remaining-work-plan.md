## 0. 取舍原则（避免过度开发）

- 只做三类事：让主干CI变绿；补齐用户能直接感知、且成本低的缺口；关闭最终验收必需的证据缺口。
- 条件型项目（没有样本、没有设备、要等自然发生）不写代码，只在条件出现时按清单观察。
- 外部接口阻塞只做一次限时探查；探查前不写实现代码。
- 新增账号写入入口、新原生路由和需求变更，先由你决定。

## 2. 实施方案

### P0 主干CI转绿

- **根因**：`tests/unit/protected-session-probe.test.ts`的`waitWrite`只等50个`setImmediate`节拍，被测代码却在等`crypto.subtle.digest`（线程池异步）。CI机器较慢，50拍内还没写入，于是失败；本机5/5通过。这是测试时序问题，不是产品缺陷。
- **改法**：`waitWrite`改为有时间上限的轮询（例如2秒内反复等待），断言不变。
- **推送前**：按CI顺序在本机跑一遍（`npm run check`、`npm test`、原生测试、`npm run build`、`npm run package`、`npm run test:ui`），一次把可能的其他红项找出来。已知旧搜索UI用例里“搜索历史也会清除”的期望早于当前文案（现为“搜索历史和本机队列也会清除”）；若该用例在CI范围内，只更新期望文本。
- **不涉及**电视包与部署。推送需你授权。
- **本地按CI顺序全跑后的实际结论（2026-10-23）**：
  - 除上面的时序问题外，CI后半段在5d005df上还有失败。用0.44.0（b6b1c2d，从未跑过CI）作基线逐项对照：
  - 0.44.0前就存在：
    - W01探针包把`product-ui.css`一并复制进`dist/probe`，触发`package.py`的精确文件清单检查（根因修在`tools/build.mjs`）；
    - 账号移除计数为3（ADR-082起同时删除续期备份槽，测试仍期望1）；
    - 账号移除提示与“本机续播记录”两处旧文案；
    - 投屏页多出一个空的`.tv-cast-state`状态元素，使旧定位器同时匹配两个元素。
  - 本次批次引起：
    - ADR-088 D3把共享默认步长改为10秒，旧套件仍按5秒点击/跳转；
    - ADR-088把DRM失败提示改为不含内部代码的文案。
  - 这些都是旧测试期望过时，不是产品回归：测试按当前行为更新；在合成片段只有8–9秒的用例里，用本机偏好固定5秒步长。

### P1-A R07 小数倍速：先探查，再决定

- **现状**：生产AVPlay只有1×/2×。ADR-086的HTML video候选已实现，桌面MP4前四档通过；真实DASH与电视都没验过。
- **探查**（ADR-086第3步）：
  - 在下一候选（0.48.0）的诊断区加一个“倍速探查”，只在你按下时运行。
  - 对一个公开视频，用现有候选后端播放生产环回MPD，依次测0.5/0.75/1.25/1.5×，用媒体时间斜率判断是否真的生效。结果显示在屏幕上，并写入脱敏日志。
  - 不改生产菜单，不另发独立测试应用。
- **决策门**：
  - **原生video能播生产MPD且倍速生效**：按ADR-086第4步接入生产，包括异步后端切换、AVPlay纳入共享解码器所有权、保存位置/暂停状态、Home清理；菜单增加0.5/0.75/1.25/1.5。估算3–5天，之后一组真机验收。
  - **不能**：不建MSE分段管线（工作量和风险都大）。建议把小数倍速正式移出v1，保留1×/2×，写ADR记录；需你确认，不静默删除。

### P1-B 详情页补全（2B精简版）

- **依据**：
  - 原生`vod-api`已经请求`x/web-interface/view`。
  - TS解析（`packages/bili-client/src/vod-catalog.ts`）目前只保留标题、UP名和分P，丢掉了简介、发布时间、统计数和UP头像。
- **范围**：
  - 简介：最多4行，确认打开全文，复用现有全文面板。
  - 发布日期。
  - 播放、点赞、弹幕数。
  - UP头像：只走现有封面加载器的hdslb主机白名单。
  - 改动只在`VodDetail`可选字段、解析、详情页与CSS；缺字段时不显示该项。
- **不做**：
  - 相关推荐、进度条缩略图（都要新的原生路由）。
  - 详情页内关注按钮（会新增写入入口，播放器里已有关注）。
- **验证**：
  - 单元：字段有界、缺失容错、外部文本只作文本。
  - 合成UI，对冻结0.47.2做负对照。
  - 打包时原生模块应与0.47.2逐字节一致。
