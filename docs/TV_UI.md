# 电视 UI 与遥控器约束

适用：Web UI 候选；.NET 保留交互规则，替换 DOM 机制。核查日期 2026-10-14。依据见 [来源 S01–S05、S15](research/tizen-best-practices-2026-10-14.md)。具体视觉数值是项目起点，不是三星认证标准，须在本机沙发观看距离修正。

## 画面与信息层级

- 16:9、1920×1080 逻辑画布；4K 视频不要求 4K DOM。播放器坐标转换集中处理。
- 初始 token：外围留白 48–64 px、正文 28–32 px、辅助信息至少 24 px、标题 40–48 px、控件高度至少 64 px。中文截断保留完整可访问名称，不通过缩小字体塞入平板式密集列表。
- 深色观看界面；选中和焦点不同，焦点使用边框/形状及对比变化，不只改变颜色。短动画、减少动画设置；避免整屏模糊和持续视频背景。
- 卡片/选项按行列对齐，列表有滚动/分页指示，新数据不抢焦点。用状态、按钮、进度、结果和恢复入口表达信息。

## FocusRouter 合同

- 同时只有一个可操作焦点；视觉状态和真实 DOM `.focus()` 一致。优先语义按钮/输入框；自定义卡片补充 role、label 和可聚焦属性。
- 搜索候选/键盘等规则网格使用显式行列邻居和区域入口；左右边界停留，竖向保列/不完整行夹紧，禁用项跳过，避免宽卡片与窄工具混排时跨区跳焦。
- 路由/区域定义初始点、方向邻居、边界、返回落点；按内容 ID 保存焦点和滚动锚点，不能只存数组下标。
- 虚拟列表保证焦点项与下一步目标可挂载；分页失败/空列表有可达重试/返回。删除/刷新/账号切换后有确定落点。
- 模态拥有焦点，背景不接收确认；关闭恢复调用点，调用点消失则选最近有效项。Loading 不锁死返回。
- InputRouter 单一入口：方向/Enter/Back 自动接收；额外媒体键先查询支持再注册。Back 10009 仅在平台适配器兼容映射；无数字/颜色键也可完成全部功能，不劫持系统 Home/音量。
- 连按方向可移动；确认、投币、发送不能因按住重复提交。一次输入交给当前拥有者，不由页面、播放器、弹窗同时处理。

## 返回与播放

返回优先级：系统 IME → 顶层弹窗/侧面板 → 播放控制层 → 播放页 → 路由栈 → 根页退出确认。IME 实际收键需 TV 验证，一次 Back 不能同时取消编辑和离页；长按退出属于系统行为。

- 播放时确认键显示/操作控件，媒体键保持可用。进度条显示目标时间，确认后 seek；不可 seek 的直播、加载和超时有反馈。倍速/切轨根据真实结果显示。
- 侧面板保留时间轴；字幕/弹幕不截获输入。暂停/seek/切 P/倍速后重新同步，以播放器时间而非累计 timer 为准。
- 投币等保留的写操作显示对象及结果，明确确认提交；unknown 提供查询入口，不自动重发。评论、回复和点播/直播弹幕只读，不提供编辑、发送或评论删除入口，见 [ADR-003](adr/003-read-only-comments-danmaku.md)。
- 投屏显示发送设备和播放归属，提供允许/拒绝/结束。手机/遥控器争用有控制权规则；LAN 命令不能直接触发账号写操作。

## IME 与无障碍

- F03 搜索由用户动作进入输入，优先采用应用内拼音首字母及候选联想；支持清空、候选选择、搜索与 Back，退出恢复原焦点。候选确认只选词，不误执行搜索；系统 IME 可用时仍统一管理输入所有权。
- 不建设评论/回复/弹幕文本或表情编辑器；评论与回复阅读不唤起输入法，弹幕观看设置不包含发送时间/颜色/位置表单。
- 0.0.9 用户反馈系统键盘貌似不支持中文，未取得可用的中文输入证据；应用内首字母路线0.0.11方向/选词USER PASS、0.0.12相关Voice Guide USER PASS；真实内容搜索未实现/验收。完整F03 保持待验收，完整中文编辑不再是 F15/F16 或 W01 门槛。
- 启动即有真实 DOM 焦点；真机检查系统 Voice Guide。图标有名称，开关/画质暴露真实 checked/selected/disabled 状态；弹窗有可读标题和原因。
- 桌面 NVDA/ARIA landmark/live-region 不等于 TV Voice Guide。弹幕、逐帧时间不持续播报；关注操作、错误和确认。字幕设置从播放器短路径可达；颜色不承担唯一语义。
