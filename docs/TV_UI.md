# 电视UI与遥控交互合同

更新：2026-10-21。Web/WGT当前路线；本页规定不可丢失的交互/工程约束，页面组织与尺寸见[大屏产品设计](TV_PRODUCT_DESIGN.md)，开发顺序与集中验收见[收口台账](PRODUCT_CLOSURE.md)。旧探针过程与原文保存在[改版前归档](archive/2026-10-21-tv-ui-before-product-design.md)，不得用其中旧“未实现/待补验”覆盖后续USER结果。

## 产品界面

- 1920×1080逻辑画布，统一缩放；AVPlay坐标转换集中在适配器。4K媒体不要求4K DOM。
- 首页/搜索/关注/番剧影视/我的/投屏为主导航，账号与设置次级；内容默认读取，诊断和包版本不占主浏览区。直播按ADR-068隐藏，真实双账号产品流程按ADR-069排除，既有数据/代码保留。
- 封面/标题、UP/P号与观看位置优先，正文按远距设计；长标题保留完整可访问名。具体token是项目目标，不是三星认证数值。
- 内容、焦点与当前选择分开；单一一致的焦点轮廓，不仅改颜色。少动画，无自动有声预览；提供减少动画与字幕/弹幕短路径。

## 单一焦点与输入

- FocusRouter拥有实际DOM焦点；InputRouter统一输入。页面不加keydown或直接调用AVPlay/Tizen全局。
- 每个区域声明入口、方向邻居、边界、Back落点。规则网格按行列显式邻接，禁用项跳过，第一列必须可达；不按不稳定几何距离推算跨区目标。
- 卡片按内容ID、身份代次保存焦点与滚动/页码；刷新、删除、乱序回包、图片就绪不抢焦点。目标消失落最近邻，空列表落可操作主入口。
- 长列表虚拟化时先挂载目标与邻居；焦点不能悬空或在屏外。模态/阅读区独占输入，背景不可确认；Loading可取消。
- 方向连按可移动；确认/提交不因repeat重复执行。不依赖数字/颜色/长按特殊键；不拦系统Home/音量。Back 10009等映射只在平台适配器处理。

## 返回、播放与图层

- 返回先归系统IME，再由当前owner处理：取消seek预览→顶层面板/确认框→播放控制层→播放器→路由。一个Back只消费一次；根页退出有确认，长按退出归系统。
- 顶级浏览区Back先回当前侧栏项；非首页侧栏Back回首页锚点，首页侧栏Back退出确认。子页/详情回原内容卡，不无条件跳首页。
- 播放5秒无操作隐藏控制；暂停/预览/加载/故障/子面板不自动隐藏。隐藏后方向/确认首键只唤回原焦点；支持的媒体键按实际播放合同执行。
- 时间轴预览后确认seek，Back取消；不在每次方向repeat发seek。字幕/弹幕以播放器时间同步，暂停/倍速/换P后重新锚定，不累计timer漂移。
- 0.39.0移除播放页重复返回/步长按钮；默认焦点暂停/继续，进度条预览后确认。Back分层退出并恢复原卡；阅读区关闭不重置播放。Home统一停声、释放媒体/监听并清叠加。
- inert只说明背景不接输入，不说明透明；播放期间隐藏非活动页面/模态阴影的绘制，退出恢复DOM/锚点。播放器显示矩形和阅读分屏只能经平台适配器，需独立实机验收。
- 画质/编码/音轨记忆为偏好意图，新内容按真实可用配置匹配、有限降级；不能把已验证设备/分辨率当永久白名单，也不能无限换源重试。
- 投屏呈现当前发送端/控制权；唤回控制栏不夺权，真实控制命令才遵守接管规则；明确允许/结束，Home后重新允许，不承诺后台唤醒。

## 搜索、账号与只读边界

- 搜索保留应用内拼音首字母候选；选词不误搜索。Back先清首字母再退输入区域，返回保留已确认词与原结果锚点。系统IME可用时仍统一管理所有权。
- 评论/回复/弹幕按ADR-003只读，没有编辑、发送或评论删除入口；搜索不是评论编辑器。
- 账号失效先取消私人请求，重新登录可回目的页；不以游客数据冒充私人读取。已有多账号存储兼容与安全机制保留，当前不要求第二账号。
- F11按独立能力暴露状态与预览/取消/确认；F14/追番与旧云进度沿用具体授权边界。unknown仅查询，不自动重发，退出页面不等于云端事务撤回。LAN命令不能提交账号写入。
- 清理/删除显示范围与保留项，默认取消；本机续播、队列、设置、云端片库和登录不得混用清理入口。

## 无障碍与交付

- 图标有名称，按钮/开关暴露真实checked/selected/disabled状态；弹幕与每秒时间不持续朗读。长标题、UP/P号与错误有可访问文本。
- 桌面ARIA与截图不能证明TV Voice Guide或远距可读；新产品界面需本机朗读/焦点/对比/减少动画检查，不沿用旧探针朗读PASS覆盖新布局。
- 每个完整模块交付方向/Back、加载/空/失败/权限/恢复规格、保留F映射与实际证据；集中验收按T1–T8，不逐按钮新增电视测试。
