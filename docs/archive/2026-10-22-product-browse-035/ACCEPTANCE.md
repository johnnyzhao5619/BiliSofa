# 0.35.0 五组体验待验归档

更新：2026-10-22。**0.35.0「BiliSofa」已升级并启动**；state/capability/install/launch明确成功。[包/源码配对](../../design/evidence/2026-10-22-browse/receipt.json)。以下五组新体验均**待用户验证**。0.34.0 A–F所请求功能组USER PASS保留于[归档](../2026-10-22-product-player-034/ACCEPTANCE.md)，不重复旧整组、长播或三端矩阵。

每组做一次，失败就停止该组，反馈位置或代码；缺数据/样本标“未测”，不要删除原记录、找第二账号或反复换视频。

| 组 | 操作与预期 |
| --- | --- |
| A 首页焦点 | 从左侧“首页”按右进入正文，再Back回导航、按右返回内容。若有一个现成无“继续观看”的身份，在该状态做同样操作；没有空态样本直接注明，不清除记录。预期右侧可达，焦点不进入隐藏控件。 |
| B 关注视频 | 使用已有保存账号进入“关注更新”，选一条有“播放视频”入口的更新，看约10秒声画并“返回原卡”。专栏/缺标识摘要保持只读；若视频更新均无入口直接反馈，不连续尝试或提供私人标题。 |
| C 连续浏览 | 首页热门和另一有足够内容的列表（搜索、关注或我的片库任选一项），用方向下连续浏览2–3行，再向上回到前面内容、开详情后返回。预期接近末行自动加载、原卡焦点保持，无须上一页/下一页；条目不足按实际终点即可。 |
| D 队列完整控制 | 从现有本机队列起播，打开“更多”，进入画质/音轨设置再返回，或调整一次倍速；有下一项时切一次，核对正确P/顺序和声画，再Back停止。预期使用完整控制栏，原队列仍保留。 |
| E 投屏界面 | 进入投屏页，先检查“接收未开启”和手机操作引导；点“开始接收”，用任一已验证官方手机App在视频内TV选择BiliSofa。看约20–30秒声画/双端时间，手机暂停继续一次，电视结束会话。预期等待区不显示无效播放控件，起播切全屏控制，结束停声并回“开始接收”。 |
