# Open source and publication

Project name: BiliSofa. Original code/documents: MIT. The initial GitHub repository should remain private; public publication requires a later explicit decision. The long-term targets are a public GitHub repository and one complete v1.0.0; only local Git/main has been initialized so far.

Before publication set the owner/final repo name, verify no credentials/device captures are included, retain all copied upstream notices, configure private vulnerability reporting and complete contribution guidance. Add meaningful CI after executable modules exist.

A signed sideload package is bound to signing/certificate/device policy. Release should include reproducible build artifacts and user-side signing instructions; keep private keys and user-specific signing configuration outside Git. Retain the author key for upgrades securely.
