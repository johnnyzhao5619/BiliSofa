# ADR-119：用户选择后启用电视内服务配置

日期：2026-10-26。关联 F01–F20 / F12 / W02 / W07。状态：源码实现与本地构建候选；未签名、未部署，未执行应用测试或新增设备验收。

## 用户决定与范围

用户明确要求：用户自行填写网站后，启用对应后端配置文件并加载地址，不再由运行代码直接写出业务域名。实施为 **0.66.0 源码候选**，保留既有 0.65.1 / e7bc374 冻结包及发布材料；不把修改后的包冒充指定提交的原包。

“后端”指电视内 Worker / WASM 网络模块；配置为 WGT 内本地 JSON，不新增常开电脑、网关或项目云服务。该设计不宣称获得第三方授权或降低法律责任，平台专用协议、认证与解析仍存在。

## 配置与启动

- `apps/tv/service-providers/catalog.json`：本地支持列表，仅把输入域名映射到固定本地 profile 文件；绝不 fetch 用户输入的网址。
- `bilibili-web.json`：具名地址、请求模板、域名校验模式、原生槽位及平台 origin 声明。地址保持可读；不是加密、混淆或保密材料。
- 首次启动只加载本地目录并显示网址输入页。仅接受无账号信息、路径、查询串的 HTTPS 网站来源 / 域名；未知网站失败并可重试，不被解释为通用浏览器。
- 用户确认后加载、校验并激活匹配的本地 profile，随后才求值 / 装配原业务入口。业务启动前不创建账号 / 媒体网络模块或预热远端请求。
- 保存普通非敏感的域名选择，后续启动重新校验本地目录和 profile；保存失败可本次使用，下次重填。设置 → 本机数据中可清除网址并退出；不删除账号、观看记录或旧未知写意图。

## Worker 和原生边界

Worker 工厂在首条业务消息之前发送配置。网络 Worker 包在 bootstrap 外壳内，收到并校验配置后才执行原 Worker 代码；各 realm 独立初始化，不以全局默认地址兜底。

C 地址引用改为地址槽位，`service-config.h` 只含稳定槽位 ID、界限和一次性初始化代码。Worker 在 `main()` / Cookie 导入之前填充槽位；native 导出检查槽位数量与每个 ID 的两段编码，拒绝缺失、错序、超长、非 ASCII、重复初始化或不完整输入。数据完整校验后一次性复制，不能部分更新。

地址模板、域名 / Cookie / CDN 检查及请求结构分别保留。用户输入不成为任意 API 或凭据目的地；Cookie 不自动附到 CDN。输入网页地址不允许关闭 TLS 验证、提升权限或加载远程代码。

## 平台与打包

Tizen CSP / WARP 的图片 origin 必须在签名前声明，由 profile 的 `platformOrigins` 在构建时生成。因此 **包内 XML / HTML 权限配置和 JSON 仍可看到域名**；本改动是配置化，不承诺发行文件里没有域名。

当前输出改为 `dist/bilisofa-configured-app`、`build/service-config/<module>`，不覆盖旧冻结的源码 / 原生 / 发行目录。全部相应原生模块按修改后的源代码重新链接，保留固定依赖、CA、许可证及来源门禁。原生桥派生配方的固定 hash 随已审阅的地址引用替换更新，未绕过 hash 检查。

打包检查保留 source / output digests、原生配置 schema、配置文件和 Worker bootstrap。域名已外置后，地址模板存在性改从受校验的本地配置读取；原生边界和凭据目的地限制没有改成任意用户地址。

## 验证和恢复边界

本轮仅执行 TypeScript 静态检查、依赖 / 全局边界、配置展开迁移校验、Samsung 原生重新链接、Web 构建和打包检查。未运行应用测试，未安装新 SDK，未连接电视、签名 / 部署、真实扫码或真实账号写入；旧设备结果不外推到本候选。

迁移时 91 个地址 / 域名模式展开后的值均与原文字值的摘要对应；这证明外置映射的一致性，不代替 UI / Worker / 原生运行时通过。错误配置停在设置 / 启动错误状态，不改动旧账号或清空本机数据；资源关闭未确认时要求退出重开。
