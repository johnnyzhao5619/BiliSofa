# ADR-095：详情页补全与小数倍速电视探查

2026-10-23；F06/F17/R07/R09/R15、U5。依据[剩余工作计划](../plans/2026-10-23-remaining-work-plan.md)的P1-A/P1-B，用户确认K1（按建议范围）。仅在`--product-detail`（0.48.0）构建生效。状态：**0.48.0已签名并升级安装/启动（平台确认，不清数据）**。用户真机结果：Z1 USER PASS；Z2 0.5×/0.75×通过、1×斜率0.81、1.25×为0.9、1.5×为1.05（均off）；Z3 FAIL（无法追番、仍为开发样式）。后续见[ADR-096](096-product-season-page-follow-toggle-and-hot-ranking.md)（0.49.0）。（[证据](../design/evidence/2026-10-23-detail/README.md)）。

## 决定

- **详情页补全（P1-B）**：
  - 原生`vod-api`已读取的`x/web-interface/view`响应里本来就有简介、发布时间、统计和UP头像，此前TS解析只保留标题、UP名和分P。现在解析为可选的`VodDetail.about`。
  - 解析宽容：单项缺失或格式不对就丢掉该项，不影响播放；Worker边界严格校验字段集合、长度、整数范围与封面主机。
  - 简介最多2000字，只保留换行，其他控制字符替换为空格，并作为纯文本显示；详情中最多4行，超出时提供“简介全文”。全文是单独一层，文字获得焦点后上下滚动，Back回到按钮（与评论全文同一模型，由`shell.modalInput`处理，无页面级监听）。
  - UP头像只走现有封面加载器（hdslb白名单、固定尺寸）。
  - 不做：相关推荐、进度条缩略图（需新原生路由）、详情内关注（新增写入入口）。搜索结果的详情是另一实现，本轮不改。
- **倍速探查（P1-A，ADR-086第3步）**：
  - “设置 → 帮助与诊断 → 倍速探查（诊断）”，只在用户按下时运行。用最近一条本机续播记录的视频，经生产VOD源与环回MPD、以ADR-086的HTML video候选后端播放（静音），依次设置0.5/0.75/1.25/1.5/1×，以媒体时间/墙钟斜率判定，偏差不超过0.1算通过（小于相邻档差0.25的一半，ADR-087）；暂停或缓冲不足记为stalled。
  - 在设置页运行，此时没有播放器模态，也就没有AVPlay解码器；候选自身的claim只保证探查内唯一。Back会停止并等待媒体关闭。
  - 生产播放器、AVPlay与倍速菜单（1×/2×）不变。结果只用于决定R07：能用则按ADR-086第4步接入，不能用则提请用户决定是否移出v1。
- **R09/F17**（已被ADR-096取代）：不新增开发。番剧详情已有“管理追番状态”：确认面板写明番剧与方向，单次提交后回读，unknown只查询。由用户指定番剧与方向做真机验收。
