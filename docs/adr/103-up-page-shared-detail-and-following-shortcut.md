# ADR-103：UP主页·投稿、共用视频详情页、关注页直达番剧影视

2026-10-23；F04/F02、R04/R05/R15、U5。按收口计划第6节（用户确认K1–K6）。仅在`--product-up`（0.51.0）构建生效。状态：**0.51.0已签名并升级安装/启动（平台确认，不清数据）；V1 FAIL、V2①③ PASS、②部分，后续见文末与[ADR-104](104-runtime-user-agent-shared-detail-everywhere.md)**（[证据](../design/evidence/2026-10-23-up/README.md)）。

## 背景

- **R04**：UP主页投稿一直被外部拒绝。WBI空间投稿接口匿名返回HTTP 412，UP卡片返回-352。
  - 限时只读核对发现官方网页接口`x/series/recArchivesByKeywords`（空关键词）：不需要签名，也不需要浏览器指纹参数；第1页按发布时间倒序并带总数，紧接着请求第2页返回HTTP 412（限频）。
  - 图文/关注动态匿名返回HTTP 412。用户决定记为BLOCKED（K2）。
- **R05**：本机匿名读取当前14个分区，全部code 0、各100条，旧-352没有复现。电视上待U5核对（A3），不改代码。
- **搜索详情**：搜索结果走自己的详情面板，没有首页详情页的简介、发布日期、点赞/弹幕数、UP头像和分P。
- **重复列表**：“关注”与“番剧影视”各有一份“我的追番/我的追剧”，用户决定由“番剧影视”统一承载（K3）。

## 决定

- **UP主页·投稿**：
  - 入口有两处：搜索中的UP结果（直接进入）；视频详情页的“UP主页”（读到UP编号后出现）。
  - 页面显示UP名，以及粉丝数、投稿数（来自已有信息），下方是投稿网格：最新在前、每页30条、上一页/下一页。只在打开和翻页时读取，不预取。
  - 被限频（HTTP 412，API -352/-412/-509/-799）时显示“B站暂时限制了访问，请稍后再试”，不自动重试，“重新读取”只发一次。
  - UP页里打开的视频详情没有“UP主页”动作，UP页不会层层嵌套。
- **原生模块**：新入口`catalog-up.c`以`CATALOG_NO_MAIN`包含冻结的`catalog.c`，原样重复其路由表，只增加`up-archives <mid> <page>`：
  - mid为不含前导0的整数且不超过2^53−1，page限1–50，ps固定30；
  - 链接到新目录`build/catalog-up`，原`catalog.c`与旧目录都不变。
- **TS**：
  - 合同新增`public-up-archives`操作和`UpArchiveCard`；
  - 解析只保留BV、标题、hdslb封面、时长、播放数、发布时间，跳过无效或重复的行；
  - 详情只在本构建保留UP编号（`VodAbout.ownerMid`），旧构建的解析不变。
- **共用视频详情页**：
  - 首页详情页（简介、事实、UP头像、分P）整段抽成`product-video-detail.ts`，原有行为不变，首页与搜索共用；
  - 可见卡片里没有缩略图可借用时，加载卡片自带的封面。
- **关注页直达卡**：“关注”只保留“关注更新”，另加一张“我的追番 · 我的追剧 → 番剧影视”直达卡，打开番剧影视的“我的追番”。
- **旧合成套件**：`product-collections-ui`移入`tests/archive/`（K4），说明见该目录的README。

## 不做

- 图文/关注动态：BLOCKED（K2），保留旧实现与记录，不重试、不绕过风控。
- 不伪造浏览器指纹参数，不冒用其他客户端的身份或密钥，不用账号读取UP投稿。
- R08继续暂缓（K5），R12、R14暂缓。

## 证据

- 原生主机测试`tests/native/catalog-up.test.py`，15条：继承的`catalog`全部检查（TLS、重定向、正文/头部上限、各路由），加上UP路由固定GET、无凭据；非法mid/page不会进入cURL。
- 单元`tests/unit/up-archives.test.ts`：解析保持服务顺序并跳过无效行；请求边界；只有本操作可携带投稿；UP编号校验，且旧构建不保留它。
- 合成UI`tests/product-up-ui/up.spec.ts`，4条，经真实的catalog Worker和页面：
  1. 详情页 → UP主页：30条、最新在前、方向键移动正确；翻到第2页15条；UP页里的视频详情没有UP动作；返回落回原卡。
  2. 搜索视频结果用共用详情页，UP结果直接打开UP主页。
  3. 被限频时显示原因，不自动重试，“重新读取”只读一次。
  4. 关注页的直达卡打开“番剧影视 · 我的追番”。
  - 对冻结0.50.4全部失败；允许嵌套UP动作的变异版本使第1条失败。

- V2：搜索UP → UP主页投稿翻页 → 播放 → 返回；视频详情页 → UP主页；观察限频提示（R04）。

## 0.51.0真机结果（2026-10-23）

- V1 FAIL：分区无法加载；从分区回不到其他位置。原因是原生自定义User-Agent被风控拒绝（-352），以及失败后焦点丢失、无卡片时上键无目标。上文“本机匿名14个分区均可读”用的是浏览器形态的User-Agent，作废。
- V2：① PASS；② 只有首页和搜索是完整详情页；③ PASS；偶有限频，稍后恢复。搜索视频结果与首页一致：PASS。
- 关注页直达卡未报告。处理见[ADR-104](104-runtime-user-agent-shared-detail-everywhere.md)。
