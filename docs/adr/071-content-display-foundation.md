# ADR-071：内容名称基础与当前直播范围

2026-10-21；对应U1、R01/R02/R15，F07/F12/F18。开发构建0.29.0位于独立`dist/u1-app`，电视仍0.28.0；这不是完整U1或新大屏界面验收。

## 名称与兼容

位置原格式/键保持；新增按固定身份隔离的`resume-labels.v1`，最多192项、196608字节，保存BV/P、标题、可选P名称与更新时间。验证后写入，损坏/未来格式不覆盖，读取副本；只有对应位置存在才存/显示名称，旧版删除位置后不展示残留名称。

点播/番剧、队列复用已取得的详情/P标题，旧匿名播放器用卡片标题，在真实进度确认后保存；目录回调本身不持久化，关闭后忽略迟到回调，相同标题不重复写。名称失败不抹除位置，标题/BV/私人字段不进诊断。

旧记录仅在当前可见页从同身份本机队列补已有标题，无可用名称保留BV。**未实现联网补取旧标题**，不请求播放源或扫描全部历史。逐P删除、仅清续播和移除账号的本地清理覆盖名称；部分失败为未确认，不影响其他身份/偏好/队列/搜索/未知写日志；旧位置可由0.28.0读取，回退无需迁移。

## 封面与范围

新增视频呈现/封面运行时合同：固定公开图床主机、受控bfs栅格文件路径，拒绝查询签名、任意地址、SVG、路径穿越和额外凭据。资源限制是后续图片适配器预算；**尚未接入封面源字段、网络加载/解码或卡片展示**，没有放宽CSP。

ADR-068通过单一范围常量门控首页直播推荐/关注直播和搜索，回调也拒绝进入；历史模块保留。投屏原政策仅允许受控`/upgcxcode/*.mp4`点播源，不新增直播/HLS路由；本轮未修改原生协议/媒体。历史直播UI场景按范围跳过，源码保留。

## 实际证据

strict/依赖边界259模块、620单元/合同（新增9项名称/封面边界），记录/范围10项、分P队列7项、普通点播/番剧13项合成UI通过。覆盖P2名称、重开、逐P清理/部分失败、局部补名、焦点/Home及入口范围。

这些不证明电视解码、远距、Voice Guide或新产品UI。无真实账号POST、无新WGT/签名/安装；旧0.28.0构建校验保持。壳层/图片加载及其余批次按[收口台账](../PRODUCT_CLOSURE.md)继续，不安排用户微测试。
