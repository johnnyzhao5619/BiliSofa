# ADR-050：已核对账号的显示资料

2026-10-19，W03/F01/F13，内部0.20.0，同一BiliSofa01.TV。0.19.0私人列表入队最小USER组通过，具体空/禁用分支未说明，停止重复。

## 来源与合同

现有身份Worker的nav GET本已读取isLogin/mid/uname。归档官方header源码同时消费`level_info.current_level`和`vipStatus/vipType`；本批只提取这三个有限显示字段，不新增请求、额外Cookie、SDK、权限、购买/历史/互动写入。外部脚本仅人工查阅，不执行或随包分发。

AccountProfile为level 0–6或null、vipStatus 0/1或null、vipType 0/1/2或null，精确三键；缺失/异常原字段降为null，不能因此拒绝合法身份或伪造等级0/会员状态。经AccountIdentity可选profile传输，IPC再次严格校验；仍须UID一致、原生关闭确认和有效会话才能激活。资料类型不包含头像/任意URL、账号ID、金额、手机号/邮箱、凭据或原始响应。

## 持久化与代次

PrivateAccount保护格式保持原六字段，登录导出明确挑选uid/name，不能把profile散入凭据结构；不保存到普通KV/诊断。AccountCoordinator只在当前active代次持有资料副本，对外再次复制；切号/游客/隐藏/失效清除，前台重新核对后才获得新资料，旧结果不覆盖新代次。摘要按钮校验页面owner，脱离DOM的旧入口不能显示上一账号的资料。

## 页面

账号管理新增“当前账号详情”，游客禁用；显示最近身份核对中的昵称/UID/等级/会员状态，以及原本机保存会话期限。会员生效要求status1且类型1或2，不一致显示未提供/不一致；status0和类型只描述当前源端状态，不保证具体内容的地区/画质/DRM权限。本机保存期限不是会员到期日或服务器保证的可用期。

打开页面不启动新网络读取；Back初始焦点并返回原入口。重新使用账号或Home恢复沿既有身份核对流程，不另建会话。未知字段有明确未提供显示。完整失效/过期/重新登录和真实双账号最终组合保持OPEN。

## 证据

单位/合同覆盖非法资料、未知值、原六字段拒绝扩展、active快照复制及隐藏/游客清理。真实生产身份Worker的合成界面覆盖登录保存格式、正常/未知资料、Back、Home更新与旧入口失效；相关私人库/队列回归。24项native运行文件复用既有字节，不重编或把旧HOST/SDK计入本批。新TV只需核对新增详情及Back，不重做登录/删账号/投屏/队列。
