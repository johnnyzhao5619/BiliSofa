# ADR-065：当前账号的视频推荐

状态：2026-10-21，W03/F02候选0.26.1；0.26.0首次读取超时，手动刷新后其余请求组USER PASS，0.26.1单次首读补验USER PASS，是否触发重试未取证，原超时根因未确认。W06 0.25.0所请求A–D获iPhone用户通过；三端/内容完整矩阵仍OPEN。F11/F14与F17真写按ADR-063暂缓，直播按ADR-057延期。

## 来源与身份

首页单独提供“当前账号推荐”，游客禁用；原游客热门、榜单/分区和搜索保持。使用当前官方网页的WBI推荐GET，每批先在独立账号jar核对nav身份，动态取得WBI公开签名材料；推荐返回的mid也必须匹配。源端退为匿名或不能确认账号时明确失败，不用游客热门填充账号推荐，不把登录成功当作已得到个性化结果。具体来源与匿名对照见[协议记录](../research/2026-10-21-account-recommendations.md)。

独立recommend Worker/C通过受保护账号能力取得私有会话，UI只接收有界视频卡及分页。C复用library.c的隔离jar/TLS/清理引擎；原library原生产模块保持。新Worker只调用身份GET和固定WBI推荐GET；继承C导出中仍有旧library只读路由字符串，不因此宣称二进制只含一个接口。无账号POST、客户端私密身份/静态签名key、风控凭证/指纹模拟或外部服务。

## 分页与交互

每次源请求12项普通网页推荐，按源顺序缓存为每页最多4卡；返回/上一页使用原快照，下一源批去除当前窗口内重复BV。保留最近32页与有限来源字段；较早页明确告知已离开缓存窗口，内存不随浏览无限增长。刷新从第1页重新展示，清除旧显示缓存；首读、继续取批、刷新分别使用官方0/4/5意图。空响应、无新视频、非普通视频、HTTP/API拒绝和格式错误分别反馈，不后台翻页或循环重试。

广告/直播/其他非普通视频卡不混作UGC播放，提示本批未展示数量；本批真实样本仅普通视频，不外推其他内容形态已验收。卡片直达已存在的账号点播链路，Back恢复原页/卡，身份切换/Home/退出取消旧读并清除该身份私有缓存，晚到结果不能复活。

## 失败和证据

保留白名单`recommend.…`细分码跨账号协调器；不传播任意异常/响应文字。HTTP/API失败可显式刷新或返回，不自动换身份、接口、UA或代理重试；身份丢失撤销私人视图。0.26.1仅对`recommend.transport_28`的安全GET增加一次350ms后重试；必须先取得实际native关闭ACK，使用相同账号/批次/意图，重新核对身份。第二次超时保留原码，HTTP/API/身份/格式拒绝与关闭未知均不自动重试。Back/Home/切账号或关闭取消等待与晚到结果。此恢复策略不证明超时的网络根因已解决；原0.26.0失败证据保留。清理必须有实际native ACK；关闭未知阻止刷新和其他能力复用。

固定32MiB WASM、20秒native生命周期、8秒单请求、512KiB正文、8KiB响应头、4096字节私有输入、同源域cookie/TLS/不跟随重定向等边界保持。SDK链接、HOST真实本机TLS、生产UI/Worker合成检查和真实电视验收分别记录。账号内容不要求与手机推荐逐条相同，也不收集用户私人标题/UID/凭据作为验收反馈。
