# ADR-061：视频评论与楼中楼只读侧面板

状态：2026-10-20，W05 F10/F15完整模块候选0.23.0；生产读取/播放页已实现，真机待验收。原0.22.0 A–D和0.22.1滚动/控制层补验USER PASS保留。没有评论编辑、发布、回复写入、删除、点赞评论或举报请求。

## 协议与私密边界

核对官方视频入口引用的[评论组件](https://s1.hdslb.com/bfs/seed/jinkela/commentpc/bili-comments.js)：主评论使用`/x/v2/reply/wbi/main`，热门mode3/最新mode2，`pagination_str`携带源端`next_offset`；楼中楼使用`/x/v2/reply/reply`的oid/type/root/pn/ps。使用nav返回的当前公共WBI材料，不沿用组件内嵌键值，不打包官方脚本。源注册/匿名请求/正文仅留仓库外`w05-comments-primary-latest.json`；公开摘要见[协议证据](../research/2026-10-20-comments-read.md)。

独立comments Worker/C模块只允许nav、view、签名根列表和固定回复GET，校验当前账号身份及BV对应aid；TLS/头/正文/期限/关闭策略沿用已验证网络基础，无新权限/依赖/外部服务。共享C编译包含旧只读playurl字符串，但操作2/3在入口被拒绝，HOST负例验证不可调用；不把字符串存在误称成具备媒体调用能力。所有评论写路由仍由打包门禁禁止。

raw rpid/根ID/游标及账号只在私有读取Worker/平台闭包；UI仅获得临时引用、作者名称、正文、时间、赞/回复数与置顶标记。oid/type/root/页码失配拒绝，大ID优先字符串，超安全整数不近似转换。正文按纯文本显示，链接/表情标记不执行、图片不加载。响应4MiB、每批64条、单文16000字符/合计262144字符，主评论/当前回复各最多50个四卡页；达到限额明确提示并允许刷新，不伪装源端自然结束。

## 分页与生命周期

主列表保留真实API批次和游标，拆成四卡页，缓存上一页；置顶及跨批重复按私有ID去重。空批保留一页并由源游标决定能否继续；重复游标拒绝，不自动追读。排序/刷新改变引用代次，旧根不能进入另一个线程；回复保留10条源批次，不把UI页号当API页号。失败只由用户手动重试；未知原生关闭使该可选读取lane不可复用，不打断视频。

播放中可打开侧面板→全文→楼中楼→回复全文；单一TvShell管理焦点、正文上下滚动与逐层Back。返回恢复调用卡/控件，不暂停、seek或重新打开解码器。换P/换集时清除旧阅读树并关闭其所有子弹窗；无关旧引用/回包不能覆盖新内容。

Home、账号切换和dispose先同步abort所有modal owner，再逐层等待清理，避免评论native close ACK延迟挡住底层播放器停声；普通Back只关闭当前阅读层，保持播放。没有新增页面键监听、原生图层调用或诊断正文。

## 出口

主机真实响应、HOST C/TLS、生产TS/Worker合成浏览器、签名安装和用户验收分别记录。0.23.0只集中核对真实热门/最新与分页、全文/回复/Back及播放不中断；空/关闭/权限失败如实保留，不用本地模拟冒充真机。F11/F14及迁入F17具体账号写入仍OPEN，直播维持ADR-057延期。
