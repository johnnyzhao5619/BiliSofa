# ADR-088：遥控媒体键与隐藏态直达操作

2026-10-23；F05/F06/F07/F10/F15/F20、R07/R11/R15、U5。依据[0.44.0前端评审](../plans/2026-10-23-batch1-remote-quickfix.md)，用户确认：D1停手1.2秒自动提交，D2停止键退出播放回原卡，D3默认步长10秒。状态：**0.45.0已签名并升级安装/启动（平台确认，[证据](../design/evidence/2026-10-23-remote/README.md)）；R1–R6 USER PASS，R7按ADR-089移除**。

## 决定

- **媒体键**：适配器先`getSupportedKeys()`，只注册电视实际报告的MediaPlayPause/Play/Pause/Stop/FastForward/Rewind。按[Samsung TVInputDevice](https://developer.samsung.com/smarttv/develop/api-references/tizen-web-device-api-references/tvinputdevice-api.html)，这需要`http://tizen.org/privilege/tv.inputdevice`（public级）。0.45.0仅为此新增该权限，打包白名单与负例同步；方向/确认/返回仍不需要注册。注册失败只记诊断`media_keys_unavailable`，方向键不受影响。键码由适配器映射为命令，经唯一InputRouter → TvShell自上而下询问各层`media()`，页面不加监听。
- **本机播放（普通/队列/番剧）**：
  - Play/Pause切换；Play、Pause按当前状态幂等。
  - Stop等同“逐层Back退出播放”，回原卡，续播位置按原合同保存（D2）。
  - FF/RW与隐藏态左右相同：进入时间轴预览，每次按默认10秒移动（D3：未设置过的默认值；已保存的5/10/30不变）；停手1.2秒自动提交一次跳转（D1），确认立即提交，Back取消。
  - 面板打开时媒体键仍作用于下层播放，但不在面板下面启动预览。
- **隐藏控制栏时**（仅本机）：确认＝暂停/继续一次（repeat不重复），并显示控制栏；左右＝直接预览并聚焦时间轴，按D1提交；上下只唤回。由隐藏态或FF/RW开始的手势才自动提交；从可见时间轴手动预览，仍按ADR-076确认提交。
- **官方投屏不变**：隐藏态任何键只唤回，不夺权（ADR-077）。媒体键只有Play/Pause作用，等同遥控“暂停/继续”按钮（既有接管规则）；Stop、FF/RW在投屏中忽略，不隐式改变手机会话。
- **面板与焦点**：
  - 画质、分P、合集、字幕语言选单打开时焦点在当前项，并显示✓/“正在播放”。
  - 各面板不再放首位“返回播放”；只有一页时不显示翻页。返回按钮仅在页面没有可选项时作为兜底出现。
  - 评论落在第一条；弹幕字幕设置落在第一项。
  - 删除“隐藏控制栏”、详情“返回视频列表”、账号“返回首页”。首页/搜索的常驻“刷新”只在失败或为空时出现，失败时显示“重试”。“我的”空的本机列表以“去首页看看”代替刷新。游客的关注、番剧页落在登录主按钮。
- **续播可达**：播放器内的“继续观看/从头播放”纳入控制行导航，出现时默认聚焦“继续观看”。
- **文案**：
  - 播放、内容、评论、互动的失败提示不再显示内部代码；代码只保存在诊断或状态元素的`title`中。
  - 写入未知仍提示“只读核对、不重发”。
  - 画质项以清晰度为主，编码/分辨率/帧率降为小字。去掉“本机播放 · P1”“只读观看设置”“评论 · 只读”。
- **提示与读屏**：
  - 普通`#feedback`提示4秒清除；含“正在/未确认/扫码/登录/失效/重新打开/权限”的提示保留到被替换。
  - 播放状态live区域只在文本变化时写入。
  - 所有焦点项保留72px滚动边距，最后一行不贴近过扫描边缘。

本条部分取代ADR-060/076及`TV_UI.md`、`TV_PRODUCT_DESIGN.md`中“隐藏时首键只唤回”的规定，仅限本机播放。投屏、F11写入合同、unknown只查询、Home停声释放、单一焦点owner不变。
