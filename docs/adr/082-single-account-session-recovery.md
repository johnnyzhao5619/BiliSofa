# ADR-082：单账号会话更新与安全返回

2026-10-22；F01/F12、W02、U4/R06。0.40.0候选，承接0.39.0三组USER PASS及随后一次点赞成功；完整U4/U5仍OPEN。

## 行为与边界

- 账号请求返回明确login或受保护会话到期，立即撤销代次、取消私人读/媒体及叠加owner；真实关闭确认后展示重新扫码入口。网络、权限、API-403不冒充登录失效；关闭未确认保持阻断。
- AccountCoordinator管理私人列表；返回的VOD/PGC、媒体中转与互动/评论/字幕弹幕能力也绑定同一代次和到期时间。旧结果、旧ready回调不能进入新会话。失效通知发起撤销，不等待调用它的页面自身，避免close/read循环等待。
- 恢复意图只含账号ID、已验证的PageRoute和ReturnAnchor；仅内存保存。原栏目/筛选意图保留，私人页数据、游标、封面租约重建；收藏夹内部句柄回到收藏夹栏目，不复用旧句柄。播放器、弹窗及任何POST意图均不恢复；无自动播放、无自动重发。
- 账号页提供“重新扫码更新此会话”。扫码结果必须是原账号，随后重新核对身份；不同身份拒绝保存，不增加第二账号流程。Back先取消扫码并保留入口，Home取消扫码/媒体，前台重进核对会话。选择游客放弃本次返回意图；显式移除沿用现有数据范围确认。

## 保护存储

[Samsung KeyManager接口](https://developer.samsung.com/smarttv/develop/api-references/tizen-web-device-api-references/keymanager-api.html)没有在Web说明中承诺同名覆盖/事务；本实现不依赖此行为。保留v1槽；每槽增加两个应用所有的v2更新bank，封装固定version、单调revision、相同身份的PrivateAccount。只先删除非当前bank，saveData真实回调后逐字回读；最新有效bank用于新版本，旧v1为旧包读取路径。不存在普通KV凭据或公共commit指针。

取消/超时不提前释放共享锁；真实回调仅清理本次bank，保留上一次已确认会话。重复revision、损坏封装/跨身份bank拒绝读取，不偷偷退回旧凭据。显式移除删除本应用该槽全部副本；队列、设置、续播及未知写日志不因更新登录而删除。旧包回退可能仍需重新扫码，不能承诺旧包使用新的bank。

## 证据与未证

[本轮回执](../design/evidence/2026-10-22-recovery/receipt.json)记录源码/工件及本地、设备平台结果。合成覆盖刷新/取消/超时/错误身份/失效/迟到结果及播放器和设置回归；均非真实账号POST。普通扫码更新、保护bank实机持久化及自然服务端失效仍需分别注明设备证据；不要求撤销手机会话来制造失效，也不清除用户数据。
