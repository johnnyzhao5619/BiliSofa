# ADR-033：内容读取入口与持久化写意图

日期：2026-10-18。范围W02/F02/F11/F13/F14；继承ADR-003、027–032。

采用有类型的内容route，页面不能传URL、header、Cookie或任意POST。首条实际装配为已有匿名popular Worker；解析、错误映射、请求代次、取消和关闭屏障归ContentClient/平台适配器。已选账号不向匿名请求附带凭据。其余内容和带身份接口在W03逐条扩展；本决策不把popular包装宣称为全部网络接口完成。

保留写操作另经RetainedWrites：确认、有效账号请求scope、未取消signal、合法action/目标、持久化pending并逐字回读，全部满足后才调用一次send。固定独立journal不含Cookie、昵称、URL、响应原文；普通设置清除及账号移除不删除它。重开pending/checking按unknown处理。损坏、未来schema、容量满或保存未确认时禁止发送，不自动覆盖/清空。

同账号同目标有未决操作时禁止新写；同一已确认操作也不自动重发。unknown只能执行只读回查；网络错误、取消、晚到结果均不能证明未应用。只有明确not-applied才允许下一次用户确认提交。每次状态更改用预期原文比较及写后回读，竞争/保存失败锁住本实例；这适用于单TV应用进程，不宣称跨进程数据库事务或恶意删除防护。

AccountWorkspace通过既有已核对身份的AccountCoordinator请求租约装配协调器。Home/切号会取消租约；已发出的写不能当作撤回，结果按unknown保留。当前没有互动提交按钮、业务POST实现或账号写入测试；W05还需操作参数/语义冲突、可查询状态与真实授权验收。W01两份未知云进度意图保持原位，不导入为可重发项、不解锁、不POST。

UI只按当前身份显示journal数量/未确认数量，不展示其他账号目标；不能通过清除偏好、移除账号或清除诊断释放防重放记录。新WGT仍需独立签名与目标机基线，桌面测试不能代替真实服务提交、持久化或清理证明。
