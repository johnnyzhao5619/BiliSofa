# ADR-054：直播试播与跨内容轨道偏好（已被部分替代）

2026-10-20，0.21.2曾使用720P验证范围、最多两种低档协商及超范围AVC的逐次确认试播。用户反馈1920×1080 AVC仍受限制，明确要求更灵活的多设备自动回退；**直播试播门禁由[ADR-055](055-runtime-media-fallback.md)替代，当前不再执行**。

保留的决定：跨视频/P/集/队列只携带质量/编码/码率语义，不复用旧catalog的nonce/key；偏好按固定身份隔离，在当前进程最多16份，自动回退不覆盖原选择。旧schema1设置/续播不变。当前具体匹配与运行时降级以ADR-055为准。

历史证据：0.21.1两间未知房间出现`live.unsupported`，只有控制条；独立公开推荐样本请求qn80/150/250均实际返回qn10000、1600×1280 AVC/AAC，证明请求档位不能代表实际源，不能唯一归因用户原房间或证明其电视解码失败。脱敏`.local/w04-212-live-public.log`与仓库外`w04-live-212-latest.json`保留；0.21.2源码/签名包及用户反馈按原版本冻结，不用新策略覆盖旧结果。
