# ADR-097：小数倍速按本机设备限制记录

2026-10-23；F06/R07、U5。用户决定（2026-10-23）：倍速保持1×/2×，小数倍速按本机设备限制记录，倍速探查保留为诊断。取代[ADR-086](086-fractional-rate-element-candidate.md)中“满足门槛后扩展生产倍速菜单”的后续步骤。

## 依据（本机UN58U8200FFXZC，真机探查）

- AVPlay：生产只提供1×/2×，均已有USER结果。`setSpeed`不能证明小数倍速。
- HTML video播生产环回MPD（[ADR-095](095-detail-facts-and-rate-probe.md)/[ADR-096](096-product-season-page-follow-toggle-and-hot-ranking.md)两轮探查）：
  - 0.5×与0.75×从正常状态起测时通过。
  - 0.25×会让媒体时间停住（斜率0，无等待，缓冲约20秒），之后测的档位仍停住。
  - 1.25×、1.5×、2×在无等待、缓冲27–32秒时只有1.09、1.17、0.85，即本机解码/渲染约1.1–1.2×封顶。
  - 唯一可行的组合是“0.5×/0.75×走HTML video、1×/2×走AVPlay”，需要播放中切换后端（每次换档在原位置重开约1–2秒）。用户选择不做。

## 决定

- 生产倍速菜单保持1×/2×，不接入HTML video后端，不提供0.25×、0.5×、0.75×、1.25×、1.5×。
- F06的小数倍速记为“本机设备限制”：不是PASS，也不是被删除的需求。编号、候选代码（`element-video.ts`等）与证据保留。若将来在其他型号或固件上复测可用，再另行决定。
- “设置 → 帮助与诊断 → 倍速探查（诊断）”保留，只在用户按下时运行，不影响正常播放。
- R07中小数倍速一项据此关闭为“设备限制”；R07其余内容（有效/失效/无权限条目、自然下一项与停止策略的有限用例）仍OPEN。
