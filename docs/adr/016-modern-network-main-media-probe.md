# ADR-016：主媒体探针的明确现代网络候选

日期：2026-10-16。W01/W02/W04/W06、F06/F17/F20。状态：候选，真实主媒体回归未验证。

独立005 HTTP九轮会话/关闭与006 TLS正负例/随机数/关闭已在本电视通过，见ADR-013/015。主0.0.54的普通UGC、巨大前置索引P2和PGC样本仍使用SDK旧网络库。独立网络通过不能证明同一现代库可供AVPlay桥、长连接、范围续读和官方手机控制使用。

新增显式 `npm run package:native:modern`。版本为0.0.55，保留BiliProbe1.Probe和原Author升级身份；默认 `package:native` 仍构造旧依赖0.0.54，旧签名包/源码与失败报告私密保留。生产runtime选择、账户批准及单一v1.0.0目标不变。现代版本仅替换完整probe的JS/WASM/data与实际依赖许可证，主UI/Worker/媒体和授权策略不改变。准备时限、五分钟媒体租期、128MiB、来源/签名期限、TLS/CA、取消/关闭ACK及unknown poison都保持。

现代输入来自已经链接的build/network-candidate/probe，依赖curl8.23.0（ADR-015窄范围补丁）、OpenSSL3.5.9、无zlib，固定Samsung1.39.4.7/32MiB堆。打包与验证同时核对recipe/lock/静态库、C输入/补丁、最终三工件、CA/全部合成媒体、全部许可证和版本身份；不覆盖build/native。不得只把build.json依赖名称改新或混用旧WASM。生成stage重建native和许可证目录以去掉旧版本余留，签名、安装独立执行。工件与源码快照精确配对。

设备顺序：自动发现启动/停止与报告关闭；随后使用未经修改的官方Android App进行媒体起播、双端时间、暂停/继续、非零Seek与停止，观察声画和读取报告。若新依赖失败，保存本版报告，再用保存的原0.0.54作为可审阅对照，不静默回退或覆盖旧结果。桌面测试与实际电视结果分别报告。独立006的证书负例证据不重新记为本主包已运行同一验证程序。

本次不放开同owner新URI，不实现选集/切P；需独立设计decoder停止/原生连接关闭、媒体代次、剩余预算与重验，现有denied_source_changed留存。用户PGC单集通过也不等于电视F17目录/选集/追番已实现。真实HTTPS账号会话、保护存储、凭据、现代三端/内容/恢复/性能与W01其余门槛仍开放。


0.0.55已取得Android同PGC单集声画/双端时间/约60秒定位/暂停继续/停止USER PASS及匹配非零目标hit/原生关闭DEVICE PASS，证据独立归档。该现代媒体样本回归允许继续ADR-017的0.0.56候选；仍不等于现代iPhone/iPad、全部内容或凭据/完整W01通过。0.0.56修改了原生换源代码，必须重新链接现代完整probe，不能复用005/006/055旧WASM；固定库/CA/许可证不变，默认legacy包继续仅内部对照。
