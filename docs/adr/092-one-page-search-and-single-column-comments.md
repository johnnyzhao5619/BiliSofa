# ADR-092：一页式搜索与单列评论

2026-10-23；F03/F10/F15、R15/T2/T4、U5。用户确认第三批F1（一页式搜索）与F3（单列评论）。仅在`--product-reading`（0.47.0）构建生效（0.47.1真机反馈修正见文末，`--product-reading-fix`）。状态：**0.47.0已签名并升级安装/启动（平台确认，[证据](../design/evidence/2026-10-23-reading/README.md)）；用户S2/S4/S6 USER PASS；S5连播记忆PASS但⚙“循环”上移FAIL；S1、S3 FAIL。0.47.1修正已签名并升级安装/启动（平台确认，[证据](../design/evidence/2026-10-23-reading-fix/README.md)），0.47.1复验S5 PASS，S1/S3于0.47.2复验USER PASS（[ADR-094](094-search-course-rows-and-ai-subtitle-files.md)）；S1–S6全部通过**。

## 决定

- **一页式搜索**：
  - 搜索页分左右两栏。左栏是内嵌键盘（`keyword-pad.ts`：A–Z/0–9六列、8个本地候选、“更多候选/用字母搜索/退格/清空”）；右栏是热搜/搜索历史按钮、类型、状态、最近搜索和结果网格（四列，与连续网格的方向图一致；见下方0.47.1修正）。
  - 选中候选词或“用字母搜索”**立即搜索**，只发一次请求，焦点移到第一条结果；输入首字母时不联网。
  - 结果第一列向左回到键盘（按几何就近）。切换类型保留关键词。
  - 关键词为空时，右栏显示最近搜索（最多8条，历史关闭时不显示），点击即搜。
  - Back顺序：先清首字母 → 再清关键词（显示最近搜索）→ 回侧栏 → 按原规则回首页/退出。
  - 全屏键盘弹窗`search-keyword.ts`保留，用于弹幕过滤词和旧构建。热搜仍为按钮打开原面板，不在右栏内联读取，避免每次进入都请求。
- **单列评论**：
  - 每条评论是一张卡：昵称首字母圆标、昵称、日期/赞/回复、正文最多4行（省略号）。确认后打开全文，楼中楼层级沿用ADR-087。
  - 聚焦到最后一条时自动在下面接续读取下一页，每个列表最多10页。接续失败保留已读内容，“重试”只补读下一页。
  - 去掉“上一页/下一页/刷新当前排序”；“热门/最新”保留在顶部。只读不变。
- 共享面板方向图（`ui/product-panel.ts`）对单列评论和设置调值面板使用单列邻接，不再套两列网格。

## 0.47.1 真机反馈修正（S1，2026-10-23）

用户S1反馈：焦点无法正确回到键盘；输入后没有确认/搜索按钮。根本原因（源码核实）：

1. **列数不一致**：CSS把结果排成3列，而连续网格的方向图按4列连线（`i%4`）。只有第1、5、9…个按钮带“左→键盘”，屏幕上第2、3行第一列向左会落到上一行末尾，看起来回不到键盘。
2. **左边缘指向侧栏**：连续网格的`left`选项是`nav-search`，被网格重连时覆盖掉页面补上的键盘目标。
3. **热搜/类型的左边缘**：0.47.0只删掉指向侧栏的目标、交给几何就近；热搜与侧栏同高，几何先找到侧栏。热搜左邻还是已隐藏的旧输入按钮。
4. **没有显式搜索键**：只有“用字母搜索”，且仅在有首字母时可用；选过候选后再改词没有确认入口。

修正（仅`--product-reading`/`--product-reading-fix`构建）：结果恢复4列，与方向图一致；网格`left`改为`keyword-key-f`；右栏所有左边缘（热搜、类型、结果第一列、最近搜索第一项）显式指向键盘；隐藏的旧输入不再参与连线；键盘工具行首位改为高亮的“搜索”键（`keyword-search`）：有首字母时按字母原样追加后搜索，否则搜索已选关键词，两者都为空时禁用。仍不逐字联网。

证据（本地）：`tests/product-reading-ui/fixes.spec.ts`两条S1回归，在0.47.1通过、对冻结0.47.0失败。真机复验S1待用户。
