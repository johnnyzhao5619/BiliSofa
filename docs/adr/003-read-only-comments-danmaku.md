# ADR-003：评论、回复与弹幕只读

日期：2026-10-14。状态：已接受，依据用户明确调整产品范围。

## 决定

电视端只提供评论、回复及点播/直播弹幕的查看，不提供发表评论、回复、编辑/删除评论或发送/编辑弹幕。移除相关输入框、编辑器、发送入口、发送参数、写接口接入及真实账号写入验收。

保留功能 ID 以便追溯，按新合同验收，不将删除旧写入要求计为功能通过：

| ID | 当前范围 | 实现归属与验收 |
| --- | --- | --- |
| F10 / F15 | 热门/最新评论、回复与楼中楼的只读阅读 | W05 合并阅读实现；验证分页、失败恢复、侧面板焦点及安全文本展示，不验收发评/回复/删除 |
| F08 / F16 | 点播弹幕只读显示及观看设置 | W05 合并显示实现；保留开关、过滤、字号、透明度、密度、区域和时间轴同步，不验收弹幕发送 |
| F18 | 直播弹幕只读接收/显示 | W04/W05；保留直播内容、播放、断流恢复及已规划的关注功能，不接入直播弹幕发送 |
| F03 | 搜索输入、联想与中文内容检索 | 优先规划应用内拼音首字母输入/候选联想，保留热搜、历史及各内容类型搜索；首字母检索不是评论编辑器 |

“只读”针对评论、回复和弹幕。F11 点赞/收藏/稍后再看/关注，F14 投币/三连，F17 追番及其他已规划的账号、进度和偏好操作保持范围；这些操作仍遵守确认、防重复与未知结果处理。尚无真实账号写入授权。

## 输入与架构影响

- 不再为 F15/F16 建设完整中文文本/表情编辑器，也不把此能力列为 W01 或发布门槛。
- 搜索仍需遥控输入、候选选择、清空、Back 和焦点恢复；系统中文键盘不是唯一候选。拼音首字母输入/联想效果须本机验证，不能将系统 IME 未通过直接转成 F03 通过。
- 评论/弹幕接收、解析、分页、渲染与搜索输入分离。只读模块不接入对应发布/删除/发送端点；文本不会作为可执行内容或隐式写命令。
- WriteCoordinator 继续服务仍在范围内的写操作。已有通用状态机/合成测试保留，历史 F15/F16 标签不代表新的写入产品承诺。

## 交付与证据

单一完整 v1.0.0、F01–F20 追踪、电视内独立运行、官方 Android/iPhone/iPad 投屏要求保持。PRD、实施计划、验收与交接提示词以本决定同步更新；历史研究和历史失败记录保留，并标注已被替代。

本次是规划调整，不是新增功能实现或验收通过。已安装内部探针仍为 0.0.9；用户本轮确认 Home 停声/返回后再播放通过，系统中文输入尚未确认可用。首字母搜索、Voice Guide、冷启动、真实内容和官方投屏等各自保留待验收状态。
