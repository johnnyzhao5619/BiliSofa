# ADR-079：控制栏常用互动与倍速选择

2026-10-22；F06/F11、U4。用户确认0.36.0所承载的A–E体验及互动读取/预览取消/Back与Home通过，另报告点赞、关注提交失败，错误码记不清；该失败保持OPEN，不能用只读通过替代写入验收。

## 常用动作

点赞、关注UP、稍后再看移入普通/分P/队列/番剧共用控制栏，无需展开“更多”。点击先读当前目标，再展示具体增删预览，默认取消；取消/Back回原快捷按钮。回读更新按钮实际状态，换源撤销旧状态；Home与源替换保留原清理规则。收藏夹继续由完整互动面板选择，不添加投币/三连入口。

只保留数字API码、固定前置条件与阶段码，不传任意服务器message、凭据或响应。日志仍在POST前落盘，unknown不重发。可逆操作获得API0而首次读到相反状态时，等待750ms再读一次GET；只有已获明确ack的可逆操作使用该一致性窗口，投币、非零/未知响应不使用。第二次仍未确认就如实显示，不继续轮询、不补POST。这是容错改进，尚未证明是用户失败的根因。

## 倍速边界

控制栏倍速改为选择菜单，显示0.25/0.5/0.75/1/1.25/1.5/1.75/2。当前后端可选1×/2×；小数档禁用并说明原因，不能把整数截断后的SDK返回记为小数倍速成功。

[Samsung AVPlay参考](https://developer.samsung.com/smarttv/develop/api-references/samsung-product-api-references/avplay-api.html)的`setSpeed(long)`列出整数参数；[播放指南](https://developer.samsung.com/smarttv/develop/guides/multimedia/media-playback/using-avplay.html)说明范围随流协议变化。这不代表全部Tizen播放技术都不能支持小数倍速。0.25/1.25/1.5等真实播放继续作为F06必需待办，需评估电视内其他播放后端及DASH/4K/音画、叠加、生命周期和解码器互斥，不能静默移出范围；本候选未实现该后端。

## 交付和验收

0.37.0使用独立`--product-actions`目录/签名指针，0.28–0.36冻结。相关自动检查只用合成账号；不自动重放用户失败的点赞/关注，也不清旧unknown。部署后只验受影响的快捷预览/返回、倍速菜单与Home，不重做已通过A–E。真实写入若需再次排查，先明确目标/方向及一次确认，依据具体返回码调查，不盲改认证或伪装官方设备。
