# ADR-067：本机观看记录与列表缓存管理

2026-10-21，F12/W05，内部0.28.0。本批为设置中的完整本机记录与当前账号列表缓存管理模块；不恢复用户暂停的F11/F14、真实追番或云进度写入。0.27.0队列A–D获USER PASS，原源码/包及独立验收回执保留；可选自然结束/历史P2分支未被用户单独分列，不自动扩展完整矩阵。

## 本机观看记录

按设置页的固定身份合并原首P64条与独立P2+128条记录，复制、按更新时间排序后四卡分页。字段仍为公开BV、P、位置/时长/更新时间，不新增登录数据、URL、CID或存储格式。设置统计包括分P；查看/翻页/删除不触发网络或播放。

记录详情可确认删除一个BV/P，或在独立确认中仅清空当前身份续播位置。清理保留播放偏好、队列、搜索、登录和未知写日志；清空普通设置与续播的原入口仍独立。任一分区损坏/未来格式时不将其当作空完整列表，也不自动覆盖；明确重置仍经已有设置入口确认。

仅清空续播先验证两分区可读，再写空首P与P2记录并分别回读。普通KV没有跨键事务；第一项已保存、第二项失败时返回unconfirmed，页面明确“可能已清除部分记录”，不冒充原子删除、不自动反复尝试。用户可重新读取核对。Detached确认和Home后的旧控件不能继续删除。

## 列表缓存

仅已核对账号显示可用的清理动作，且单独确认。通过账号租约及runtime acquire取消旧读取、等待原生实际关闭、递增运行代次，再清空推荐window/索引/来源、云历史游标/页、收藏夹引用、关注更新offset/页；下次打开列表重新读取。清理本身不启动Worker或发出HTTP请求，不注销账号或清除保护jar、本机数据、写意图。

旧请求不能重新填充缓存；关闭未知拒绝成功/阻止能力复用。Home/Back/切账号取消，模态只等待native操作完成，不等待会重建私有视图的外层协调promise，以免清理互等。UI只显示固定结果，不回传私有游标/来源ID或字节释放估算。

## 证据与验收

静态/单元、生产UI/Worker合成组合、原生字节/整包门禁和真机观察分开记录。无新增SDK/API/权限/依赖或账户POST。真实电视集中验收设置/记录/取消/单P删除及缓存清理后仍登录；全部续播清空可留作可选，避免为测试删除已有私人位置。完整F12故障/性能与跨身份矩阵仍归W07。
