# ADR-060：弹幕连续绘制与播放控制层

状态：2026-10-20，0.22.0的A–D所请求组获用户通过，同时报告滚动弹幕跳动、控制栏不能隐藏。修复0.22.1的滚动连续性/暂停继续、隐藏唤回/字幕空间/返回所请求补验已获USER PASS；原工件与单独用户记录保持，不重测整组。

原因：旧RAF只重画AVPlay离散时间回调缓存的位置，相邻回调之间坐标相同；控制栏没有隐藏状态。当前适配器未记录实际回调间隔，不把桌面合成间隔说成电视测量结果。

采用独立`OverlayMotionClock`：仅在playing且不seeking/buffering时，根据最近真实时间和单调时钟计算逐帧弹幕位置，外推最多1秒实际时间、按已接受倍速缩放；缺失回调达到上限即停，真实后退/换源/暂停/缓冲/倍速变化重新锚定。字幕仍按原始媒体时间匹配，续播记录、投屏时间、seek目标和持久数据不使用视觉时钟。AVPlay缓冲状态经适配器进入媒体snapshot，不由UI访问SDK。

播放控制层使用同一TvShell/modal owner：正常播放5秒无操作自动隐藏，也有“隐藏控制栏”；暂停、预览、加载/跳转/错误及子弹窗不自动隐藏。隐藏时仅全屏透明唤回按钮拥有真实DOM焦点；确认/方向首键只唤回并恢复原控件，不同时执行。Back先取消预览，再隐藏控制层，隐藏后再Back离开；明确的“返回原卡”仅关闭属于自己的顶层modal，不能误关其他弹窗。暂停/故障状态保留可达恢复操作；Home沿原owner清理。

隐藏时字幕回到底部60逻辑像素；显示时避让实际控制栏，字号/语言/偏移与账号数据不变。控制层不新增全局键监听，不接管Home/音量，不添加网络/权限或账号写操作。当前浏览器逐帧坐标与截图只证明合成检查；真实设备表现按[当前清单](../CURRENT_DEVICE_TEST.md)补两处。
