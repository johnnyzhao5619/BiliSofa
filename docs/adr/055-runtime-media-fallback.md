# ADR-055：运行时媒体选择与自动降级

状态：2026-10-20，用户明确要求取消固定已验证范围拦截并适配多台Samsung TV。0.21.3候选采用本决策；替代ADR-054中的720P/有限试播确认门禁，设备验收事实仍保留。

## 决策

**已测能力用于报告证据，不作为播放白名单。** 不按U800FD、ProductInfo读取权限或旧720P样本阻止其他电视起播。平台适配器检查实际播放器/屏保SDK入口；返回的是本地解析/MPD可表达的候选配置（AVC/HEVC/AV1、AAC/EAC3/FLAC及有界尺寸/fps），不是所有电视硬件支持声明。维持包最低平台和实际WASM/网络运行条件；其他设备尚须实测。

用户反馈0.21.2仍在1920×1080 AVC提示附近失败；未提供实际prepare错误码，不记为1080P解码器不支持。本次删除额外试播确认。实际返回的可表达源直接交AVPlay；无论1080P或4K，都不因“尚未验证”而提前拒绝；无格式解析路径、加密/权益失败仍如实处理。

- **直播**：不预先把实际源压到720P。准备/播放失败时，在本房间真实声明的qn中，从低于失败实际qn的下一档开始，最多自动降级3次。每次核对实际返回qn/编码/尺寸；接口忽略低档、仍返回相同失败源时，不再次进入decoder，继续剩余低档或明确结束。源端只有一档且该档实播失败，则无下一档可切，不能伪造CDN变体。
- **点播/番剧/队列**：新内容按身份隔离的临时语义偏好绑定本catalog；没有偏好优先普通AVC/AAC。实际准备/播放失败后，选未试过的、不高于失败画质的实际轨道组合，优先AVC/AAC与相近低档；每个媒体owner最多4次不同组合（初次+3次回退）。保留同一内容、实际进度和暂停意图；不跳到另一内容、不把自动回退覆盖为用户原始偏好。
- **失败边界**：只有旧decoder与transport都确认关闭才能换源。取消/Home/Back、账号/权限/TLS、无效协议、seek/control失败、关闭未知不通过换轨重试掩盖。直播已有网络恢复最多两次，和质量降级分别限额；成功推进30秒后只可重置网络恢复次数，不重置降级配额。
- **产品反馈**：显示实际源和回退状态；不能将候选可选、prepare成功或接口标签当作真实分辨率/HDR/声画通过。解析正文/尺寸/内存等安全上限继续保留，不是硬件能力限制。

[Samsung AVPlay API](https://developer.samsung.com/smarttv/develop/api-references/samsung-product-api-references/avplay-api.html)定义prepareAsync及不支持格式、连接等错误；适配器只映射固定错误枚举，不保存含URL/请求头的原始错误。ProductInfo提供型号等诊断资料，不能据其读取失败推断解码器不可用，见[官方ProductInfo API](https://developer.samsung.com/smarttv/develop/api-references/samsung-product-api-references/productinfo-api.html)。本决策不使用浏览器canPlayType替代AVPlay实播证明。

## 验证边界

本地覆盖未知型号/型号权限失败仍可起播、缺SDK明确错误、1080P/4K直接进入合成decoder、真实高档prepare失败后下一档、接口忽略降级无循环、点播高编码转AVC/AAC、暂停/位置/原偏好保持、源权限和关闭未知不重试、Back取消回退。生产TS/Worker/私密端口为真实代码，native与decoder是合成替身。

电视只补直播正常声画/返回和自然发生的跨内容回退；保留A–C/D列表已通过结果，不重做无影响组。F19权益、真实高码率/4K/HDR与其他型号未验证继续开放；不能为完成验收购买权益、绕过官方发送端限制或重用账号写授权。
