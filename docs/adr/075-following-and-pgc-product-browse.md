# ADR-075：关注与已追番剧的产品浏览

2026-10-21；U2/R04/R06/R15，F04/F17。独立0.33.0源码候选`dist/product-collections-app`，不作为独立产品版本。已安装包仍0.28.0；0.28–0.32冻结工件保留。无新WGT、签名、部署或真实账号写入。

## 页面与来源

“关注”默认读取网页关注更新摘要，同页可切我的追番/追剧；“番剧影视”提供搜索入口和已追列表，不虚构公开推荐榜单。游客仅显示可用公开搜索与登录行动，私人分类不可用且不发私人读取。进入搜索时选中UP/番剧类型，复用统一搜索的关键词与历史。

四列紧凑文字卡展示标题、类型、作者/发布时间，或更新/源端观看状态。现有源未提供安全封面时不填充空海报；内容/语义与实际来源一致。更新源无可播放ID，详情只读，不能伪造播放、UP主页或专栏正文。追番/追剧含有效季ID，可关闭详情后进入既有季/集媒体工作区，Back逐层返回原卡；不自动改追番或云进度。

现有Worker/私有合同与安全解析保持。统一私人读取通道仅增加关注更新及追番/追剧列表命令；列表查询不获得写权限。R04完整动态/UP来源仍BLOCKED，本实现不能关闭它；F17真实写验收仍待具体授权。

## 请求、焦点与恢复

分类分别记页码与原卡，更新摘要无稳定源ID时用页内位置；同账号Home重新核对后私人页从第一页读取，账号变更清内存而不删除保存数据。切栏目取消旧请求，等待原生关闭确认，使用视图代次拒绝迟到结果。owner关闭只等待native job，不等待可能重建页面的workspace.read，避免身份失效清理互相等待。原生关闭未知时禁用查询入口，壳层拒绝继续复用资源；普通网络失败可刷新/返回。

卡片首列左到当前导航，上到分类、下到分页，详情回原卡。壳层在异步原卡尚未挂载时优先选择页面声明入口，而非误落首页导航；结果就绪后恢复有效原卡，用户移到侧栏/弹窗时不抢焦点。关闭详情后才打开季/集；缺播放器时给出反馈，不静默无操作。

身份丢失继续采用既有流程：立即取消私人读并回游客首页；重新登录回原目的页仍属R06/U4，不能用本轮游客清理通过冒充完整恢复验收。

## 证据与剩余

275模块strict/依赖边界、631单元/合同、32项桌面合成UI通过（新模块9、统一搜索8、片库9、壳层6）。新模块覆盖游客零私人读、分页/分类记忆、季/集播放返回、快速取消、失效清理、关闭未知及Home重读。最初返回焦点问题已修复；私人季/集夹具与游客/隐藏控件断言校正，失败日志保留。
