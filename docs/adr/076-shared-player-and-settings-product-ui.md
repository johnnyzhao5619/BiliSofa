# ADR-076：U2账号设置与U3统一播放阅读表现

2026-10-21；U2/U3，F01/F05–F12/F15/F17/F20。用户要求“完成U3之后部署到电视并给验证清单”，因此在此完整模块里程碑部署0.34.0「BiliSofa」，不等待U5，也不逐控件发探针。旧0.28–0.33工件与工作区全部保留；无Git发布或真实账号POST。

## 表现与业务所有权

账号改为当前身份/保存会话和扫码两区；只提供单账号产品流程，不删除历史槽位。设置分播放、字幕弹幕、搜索记录、本机数据、账号、帮助与诊断，重用原控件/回调。各身份原存储、保护会话、未知写日志及删除预览边界保持。字幕弹幕默认设置使用既有同身份存储，损坏/未来格式必须显式重置，不能自动覆盖。

普通视频、队列、PGC与官方投屏共用DOM表现：标题/来源或控制权、真实进度、可聚焦时间轴、主要操作及四列“更多”。左右只预览，确认才交现有媒体协调器跳转，Back先取消预览；更多打开或预览期间不自动隐藏。5秒无操作隐藏，方向/确认首键只唤回。自然结束提供直接重播。投屏唤回/预览不夺权，实际遥控命令才走原控制权合同；显式结束直接关闭所属会话，不能被“Back先隐藏控制栏”截断。

选P/集、轨道和字幕弹幕设置改右侧面板；评论/回复只读、全文独立滚动，Back逐层回原入口，不重开媒体。所有焦点仍为实际DOM焦点，经既有InputRouter/FocusRouter与返回栈处理；没有页面keydown、额外焦点owner或页面直调AVPlay。Home继续由原生命周期取消/关闭Worker与decoder，迟到回调受原代次门禁限制。

## 工件与安全

独立`dist/product-player-app`/0.34.0，明确构建、打包、签名、部署flags，应用ID与Author保持，升级不卸载/清数据。打包保留来源hash、17原生模块/68项资源、CA/TLS、固定网络范围和许可证；仅精准补齐三个既有公开图床HTTPS connect-src及本地blob图像，不增加远程脚本或任意域。签名包/证书/设备地址/原始日志只在仓库外保护目录。

## 证据与出口

280模块检查、631单元/合同、79相关合成UI、6项新包负例通过。冻结0.28–0.33的162个文件及manifest未变；本轮238个源码输入与27个界面工件对应签名/部署hash。首次投屏结束缺陷已修复；误选暂停互动套件后停止并按保留阅读范围重跑，不记停止套件通过。原生模块未改，未宣称新增decoder/HDR或真实网络通过。

0.34.0自有profile签名、平台安装升级/启动明确成功；用户尚未验收新UI。按[有限A–F](../CURRENT_DEVICE_TEST.md)集中验证，不重做已通过长播/三端矩阵。[布局与Back合同](../design/U3_PLAYER_LAYOUT.md)、[合成截图/配对回执](../design/evidence/2026-10-21-u3/README.md)可审阅。
