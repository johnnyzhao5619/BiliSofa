# ADR-090：播放器主行、⚙设置侧栏、长按加速与连播倒计时

2026-10-23；F05/F06/F07/F08/F10/F11、R07/R15、U5。用户确认第二批E1（同一视频连播）与E3（互动留主行）。仅在`--product-polish`（0.46.0）构建生效；更早冻结构建不变。状态：**0.46.0已签名并升级安装/启动（平台确认，[证据](../design/evidence/2026-10-23-polish/README.md)）；用户所请求P1–P7 USER PASS**。

## 决定

- **主行**（本机播放）：`暂停/播放 · 上一P · 下一P · 选择分P · 弹幕开关 · 字幕 · 评论 · 点赞 · 关注 · 稍后再看 · ⚙设置`。
  - 图标用内联SVG加短文字，不引入字体或图标库。
  - 暂停/播放的图标与文字随实际状态切换，可访问名保持“暂停 / 继续”。
  - 点赞/关注/稍后再看为图标按钮，聚焦时显示文字。没有账号互动能力时（游客）这三项隐藏，不显示禁用灰按钮。
  - 标题行显示UP主；播放中不再显示“正在播放”状态行。
- **⚙设置侧栏**取代“更多”网格，里面是画质/编码/音轨、倍速、连播、循环、合集、收藏夹、加入本机队列。
  - 打开时，这些按钮移入右侧列表，焦点落在第一项可用项；关闭时回到隐藏行，状态更新逻辑不变。
  - Back关闭侧栏并回到⚙；从侧栏打开的选单，Back回到侧栏。
- **弹幕一键开关**沿用现有叠加偏好与保存路径（`VodOverlays.toggleDanmaku`），偏好格式不变；“字幕”打开原弹幕与字幕设置。
- **长按/连按加速**（纯函数`SeekGesture`）：同一手势内按1–3次每次一个步长（默认10秒），第4–6次至少30秒，之后至少60秒。手势在提交或取消时结束。提交规则沿用ADR-088（隐藏态与FF/RW停手1.2秒提交，可见时间轴确认提交）。预览显示目标时间与差值。
- **连播倒计时（E1）**：
  - 同一视频的下一P、合集下一项、番剧下一集在播完后显示“即将播放：…”及5秒倒计时，默认焦点“立即播放”。“取消”或Back停在结束页，焦点到“从头重播”。
  - 只在循环关闭且确有下一项时出现；不可播放项不在可播序列中（沿用`playableVodSegment`）。
  - 连播默认开启，可在⚙关闭。**本次只在当次播放会话内记住**：为保证可回退到0.45.0，不修改本地偏好格式。0.45.0解析器要求偏好恰好两项，新增字段会让旧版读失败。
  - 本机队列沿用其原有连播开关与即时切换，不加倒计时。
- **投屏播放器不变**：仍是原“更多”布局与控制，仅共享时间轴样式；不新增投屏命令。

部分取代ADR-076的“四列更多”（仅本机播放）。ADR-088的键位合同、F11写入合同、投屏所有权不变。
