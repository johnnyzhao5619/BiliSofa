# ADR-073：继续观看与统一片库

2026-10-21；U2、R01/R07/R15，F05/F07/F12。0.31.0为独立开发候选`dist/product-library-app`，电视仍0.28.0。无新WGT、签名、安装或真实账号POST；0.28/0.29/0.30冻结工件保留。

## 功能与数据

首页有记录时显示四项“继续观看 · 本机”，含视频/P名称、已看/总时长和进度；无记录不留空货架。网络读取失败不影响本机续播。只解析当前可见页的名称，从同身份既有队列补显示名；缺名保留BV，不联网补取、不覆盖损坏/未来格式。已有位置格式与键不变。

“我的”同页分类为继续观看、本机队列、稍后再看、云端历史、收藏夹；四列卡片、分页、详情与返回。游客的私人分类禁用并提供账号入口。队列按BV＋P保留顺序、去重、上移/下移、连播与从此项播放；逐P删除默认保留，实际删除后落原位置最近邻，保留其他P、队列/续播、偏好和未知写日志。云端分类只读，本机入队不改变云端。

有效普通视频按明确P播放。历史缺P/缺BV、PGC等没有可用播放标识的卡片仍可读，不能擅自播放首P；稍后再看失效项不开放播放。本轮未补私人PGC播放标识/权益，相关R07仍OPEN。云历史进度只展示，播放遵循本机位置；不恢复云进度写入。普通详情先关闭，再创建已有VOD/队列媒体owner，直接返回原卡；播放器视觉仍待U3。

## 所有权与表现

每个分类记忆页码/焦点；收藏内容子层独立owner，Back回原夹。新分类先取消旧网络并等native ACK，拒绝旧回包；旧卡暂不可操作，错误可刷新/返回。账号失效同步清除旧视图，关闭只等待native job，不能等待会重建页面的workspace.read。账号更换清浏览内存；同账号Home后重新核对时使私人游标失效，从首屏重新读取，保留本机记录。

首页本机卡与异步公共列表分别拥有焦点，公共返回不抢本机焦点。首列左进当前导航，返回/侧栏右按稳定ID恢复；无稳定源ID时按位置回退。所有命令仍经统一InputRouter/FocusRouter，没有页面keydown或直接AVPlay访问。

私人DTO仅增加可选公开封面引用，来源字段未提供/不安全时使用类型后备，不虚构封面、UP或时长。复用ADR-072的HTTPS/CORS/字节/尺寸/并发/取消策略。稍后再看IPC上限8KiB，云历史批次上限192KiB以容纳100条受限引用；原HTTP响应上限仍512KiB。合包时UI与Worker必须按同一manifest配对；不改保护凭据或持久化数据格式。

## 证据与剩余

272模块strict/依赖边界、631单元/合同通过；本模块9项＋壳层7项＋旧稍后看8项/历史9项/收藏13项合成UI通过。覆盖P2、名称与重开、局部删除/最近邻、队列顺序与下一项、真实Worker传递公开封面、短收藏夹翻页禁用、私人取消/失效/Home及访客数据保留。C、AVPlay、账号和图片使用合成边界，不证明真实账号片库、TV图床CORS/解码、Voice Guide、远距或性能验收。

初次单元复跑发现旧F17合成取消测试用8毫秒猜测POST阶段，改为等待合成阶段事件，应用代码未因此改变；失败及最终日志保存在`.local/u2-library/`。没有调用真实追番写接口或消耗任何新写入授权。
