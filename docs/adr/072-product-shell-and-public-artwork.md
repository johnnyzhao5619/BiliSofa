# ADR-072：大屏壳层、卡片与公开封面

2026-10-21；U1/R15、F02/F03/F06/F12。独立开发构建0.30.0位于`dist/product-ui-app`，电视仍为0.28.0。保留0.28.0与0.29.0冻结目录；不生成、签名或部署WGT。

## 行为与边界

首页自动读取游客热门或当前账号推荐；四列封面/标题/UP/时长卡片，热门/全站榜/分区、分页和刷新。视频搜索复用首字母候选、热搜、历史、匿名WBI Worker和同一套卡片；UP/番剧搜索保留现有面板，尚未统一成单一类型切换器。详情提供首P播放/本机继续、从头、本机入队；显式播放意图不会再次弹出续播确认。详情完全关闭后才创建原媒体owner，返回直接到原卡。

六个主目的地与次级账号/设置经同一InputRouter/FocusRouter；顶级切换替换导航根，按身份保存内容锚点/页码，Back先回侧栏，再回首页，首页侧栏Back才退出确认。模态优先、真实DOM焦点、Home停止和账号代次保持原机制。推荐关闭只等待底层native job，不能等待会在finally中重建页面的workspace.read，避免互相等待。

`product-page.ts`装配目的地，不把页面实现继续堆入入口文件。关注、番剧、我的、投屏和账号/设置已保留可用入口，但其列表/面板及播放器尚待U2–U4统一视觉；继续观看货架、完整UP/动态、会话恢复等未完成项见收口台账。直播不展示；互动门禁/未知写日志保持，无真实账号POST。

## 封面安全与失败恢复

热门、排行榜、推荐、视频搜索只透传规范化的公开图片引用。允许i0/i1/i2.hdslb.com的受控bfs JPEG/PNG/WebP路径，拒绝凭据、查询/片段、端口、控制字符、编码/路径穿越及SVG。兼容来源HTTP/相对协议，但加载统一HTTPS。

独立适配器使用不携凭据、禁止跳转和无Referrer的CORS fetch；每图≤1MiB、尺寸≤2048²、8秒截止，全模块共享最多2个活动任务和16个排队任务。检查栅格头及动画标记后解码，重采样至≤800×450，以拥有明确归属的blob URL展示；刷新/换页/Home清理和撤销URL。CSP只新增blob图片及三个精确HTTPS连接源，WARP同样限定这三个源。不引入外部代理、磁盘图片缓存或账户Cookie。

坏格式、断图或CORS失败保留标题/时长和可选择卡片；原内容在安全读取失败时仍可浏览，并标为上次内容。图片完成不抢焦点。此适配器的TV CORS/解码兼容和内存预算**尚未真机验证**，不可据桌面测试宣称达标。API语义参考[Fetch凭据](https://developer.mozilla.org/en-US/docs/Web/API/Request/credentials)、[重定向策略](https://developer.mozilla.org/en-US/docs/Web/API/Request/redirect)与[CSP图片来源](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/img-src)。

## 证据

strict/依赖边界267模块、625单元/合同通过。新壳层7项＋记录10项＋逐P队列7项＋媒体22项合成UI通过；11项直播场景依范围跳过。覆盖真实生产Worker/解析器与合成C/媒体边界，不能算真实B站接口或电视媒体验收。初次焦点恢复缺陷已修复；回归测试按实际控制层判断Back次数，移除按构建目录硬编码的判断。测试服务端口冲突只属本地启动失败，后续串行运行。
