# ADR-043：F02 当前公开分区榜单

状态：实现候选；实际TV读取/内容匹配仍待。范围W03/F02，不替代完整基础分区/个性化推荐。

沿ADR-035的固定匿名排行榜通道，增加`public-category-ranking`，仅接受生成的数字ID白名单；结果回显分类，父侧同时核对scope/operation/categoryId。全站榜操作保持，无自由URL/Header/Cookie/私有请求。四卡分页、最多100卡/25页；当前内存快照只属于一个榜单键，换分区/全站/其他route/刷新即失效，旧原生关闭未确认则封锁复用。失败不保留可操作旧卡，不自动重试；用户显式刷新或重新选择分区。

## 来源与取舍

实际官方header脚本含30个UGC顶级分区，但这不证明30类都有排行榜。进一步读取官方排行榜HTML及其`index.55b42adc.js`（HTTP200，SHA256 `20904573916562ac9cd5e42fe32feb0d6f9d2aadad341e3736df807f80860b50`），确认`rid:tab.tid`、`type:all` GET `/x/web-interface/ranking/v2`，以及公开配置`channel_list.popular_page_sort`的来源。

匿名读取网页同一公开配置HTTP200/API0，45943字节，SHA256 `eec0edd0eb7d826cb54821360783921f50f2bc5124dbf77689c95a56796fe5ba`。其榜单排序包含14个普通视频分区；其余PGC榜单有独立协议，不接进本通道。只提取事实ID/名称/route，原始JS/配置不随应用执行/分发，不使用账号或客户端鉴权身份。配置中的appKey仅记为公开前端命名空间来源，不作为本应用认证材料；电视运行时不请求该配置。

`packages/contracts/data/categories.json`为本次冻结事实来源；`tools/category-data.py`生成TS与C白名单，构建/打包检查一致性；原始材料私密归档。UI每组六项、共三组，选中后由单一shell关闭模态，再发起读取；Back只返回原列表，不触发请求。页脚增加选择/刷新，保留八项首页工具的四列布局。数据以文本渲染，复用既有媒体owner和原卡返回路径。

## 失败与边界

旧region接口单次返回API -404，未保存HTTP状态，不推定状态。当前分类ID1005的榜单一次独立HOST请求HTTP200/API-352，未取得成功内容；不能由此判定永久不支持，也不能由本地合成成功宣称真实榜单可用。没有UA/代理轮换、认证绕行或自动重试。TV只做一次新增分区组；若API拒绝则记录阻塞并停止该组。

30类导航目录未全部变成榜单功能，其他分区浏览继续OPEN。个性化推荐、完整PGC榜单及W03私人内容不在本批关闭；权限/存储/已有账号写边界不变。F03四类搜索既有USER最小组复用，不再重复。
