# ADR-062：明确目标、持久确认与分项回查的账号互动

状态：2026-10-20，W05 F11/F14实施；真实账号验收OPEN。不改变ADR-003只读评论/弹幕或ADR-057直播延期。

## 行为与接口

播放页提供点赞/取消、指定现有收藏夹增删、稍后再看增删、关注UP/取消、投1或2币及三连。先核对当前身份、BV→AID/UP、本人状态、完整收藏夹/稍后再看列表与硬币余额，再显示具体目标、方向、数量和不可撤销事实。确认默认焦点在取消；确认后按钮不可再次提交，返回只离开，不撤销已提交操作。

当前官方网页的三连接口只接收AID，由服务端决定投币数量/默认收藏。为满足本项目明确数量和指定夹的合同，本实现将一次三连确认展开为“点赞（已有则跳过）→所选数量投币→指定夹收藏（已有则跳过）”。每项有独立持久标记、一个固定POST及独立回读；失败/取消即停止后续项，部分成功如实显示，不自动补发。不是跨接口原子事务，也不冒称使用官方三连端点。协议来源见[研究记录](../research/2026-10-20-video-interactions.md)。

## 所有权与网络

`VodAccess.interactions(catalogId)`仅对已验证账号开放。独立可选Worker/C lane不获取或关闭媒体decoder；每个批次重新Nav核对UID、重新读取BV绑定及当前状态，写前拒绝失效的预览、改变的UP/状态/硬币基线、过期会话、错误数量/夹。关注区分普通/悄悄关注的取消动作。私有ID/CSRF/Cookie不进入UI或诊断；公开UI只持有临时夹key。TLS、固定api.bilibili.com路由、禁重定向及有界解析保持，无新增应用权限/外部服务。

预览token一次使用、120秒到期。源代次/账号切换/Home/退出先撤销能力和确认页，再等原生关闭；旧关闭回调不能关闭新源；最终close立即释放该lane的私有会话引用，不修改保护存储中的账号。读取/错误不停止正常媒体，不自动重试网络请求。

## 持久写入与兼容

新增`bilisofa.video-interactions.v1`，保留原`bilisofa.retained-writes.v1`和W01两次未知云进度记录；没有清空、迁移重发或删除入口。新日志先咨询旧相关未知标记和旧投币/三连标记，不能通过换key绕过它们。旧进度标记不被改写为互动结果。

每项POST前必须CAS写入并回读pending；失败、损坏、未来schema、超过256项或关闭未确认均锁定。日志只留账号/对象ID、操作/数量、回查必要状态和消耗记录；不保存Cookie、CSRF、标题、UP/夹名称或原始响应。pending重开视为unknown。

可撤销操作只在精确对象/夹的实际状态回读后确认或标明当前未应用；新操作仍需新预览确认。投币仅在本次API0且本人该BV累计投币数恰好增加所选数量时确认。未知投币不能因后来计数变化或其他状态查询解锁。已确认1币后，可在新基线/剩余额度下另行明确确认1币，原标记保留，不能复用旧基线/token。API0不是云端状态证明。

## 证据与验收

本地合成账号覆盖增删、精确夹/数量、三连部分成功、取消/重复/重开、防旧日志绕过、失效代次、Home与真实关闭、固定TLS/方法/参数及包来源。没有执行真实账号POST。整包和实机结果见[测试报告](../TEST_REPORT.md)与[当前验收](../CURRENT_DEVICE_TEST.md)。真实F11/F14及移交F17账号写入需另行具体授权；不因此关闭W05或v1.0.0。
