# ADR-081：稳定浏览、按需封面与目标互动

2026-10-22；F06/F11/F12、U4/R03/R15。承接0.38.0用户失败反馈和新的遥控要求；不修改直播/双账号/F14范围，不清数据或旧unknown。

## 复核及决定

[技术复核](../research/2026-10-22-browse-review.md)记录代码证据、外部资料和未证边界。原网格只移除行而没有保留整体滚动范围，迟到预取还可能移除中间行；图片是全量排队、16个待处理即放弃、无跨页去重；常见CDN resize后缀会丢掉可用封面。旧快捷操作重复核对整组状态，普通成功路径约22次GET/POST往返。

0.39.0保持Web/DOM单焦点，不引入React/Android运行时：

- DOM最多3批/12卡，缓存8批/32卡、5分钟。用测量的行步长保留前后虚拟空间，禁用浏览器自动锚定，保留原卡位置；预取回包先缓存，不在用户已回看时打散连续窗口。刷新/查询/身份owner结束照旧失效，缓存回看不请求后台。
- 公共封面统一为受控原图引用，严格归一化已知resize后缀后请求固定480×270 WebP；不接受任意目标或签名参数。可见/邻近区域、焦点触发加载，两个并发、共享去重与URL租约；32卡页缓存不再同时抢图。全局最多48个条目，空闲LRU最多16，8MiB/48缩略图像素预算用于淘汰空闲项；固定字段/字节/尺寸校验、omit Cookie、拒绝redirect/CORS限制均保持。临时网络/429/5xx仅一次有限重试，失败保留占位、下次有效进入可再核对。最后视图关闭取消队列、释放全部URL。
- 快捷状态分toolbar/like/follow/watch-later查询，写前仍核对实际身份、BV/UP与本操作状态；写后只读同一族。本人Nav余额在同批复用，收藏夹/余额不阻塞三项按钮。普通成功路径10次往返，API0短窗延迟GET仍仅一次；这是请求数减少，不是已测电视延迟保证。
- 关注消费者只使用官方脚本实际依赖的attribute；目标来自固定fid请求和已核验视频owner，不再用未文档化mid元数据推断目标。未知attribute仍拒绝，跨UP预检不放宽。0.38.0原始响应缺失，不能提前证明invalid真机根因已闭环；点赞-403仍是服务端拒绝、根因OPEN，不伪造客户端/风控字段或自动重发。
- 播放控制栏隐藏返回原卡、两个步长预览按钮；默认可播放焦点是暂停/继续，进度条左右预览/确认跳转保持。Back依次取消预览、关子层/更多、隐藏控制栏、退出到原卡。Home清理、队列/PGC共用此合同。投屏“结束会话”是授权出口，保留。

0.39.0独立输出/签名/部署，0.28–0.38冻结；代理不执行真实账号POST。集中补验本轮播放焦点/Back、深列表/封面、关注读取及操作等待，点赞不重复盲测。U4/U5、R06/R09、F06小数倍速和最终性能保持OPEN。
