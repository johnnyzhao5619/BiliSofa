# ADR-093：设置左右调值、Home返回续看与连播偏好

2026-10-23；F06/F07/F08/F09/F12、R01/R13/R15、U5。用户确认第三批F2（回详情续看）与F4（记住连播）。仅在`--product-reading`（0.47.0）构建生效（0.47.1真机反馈修正见文末，`--product-reading-fix`）。状态：**0.47.0已签名并升级安装/启动（平台确认，[证据](../design/evidence/2026-10-23-reading/README.md)）；用户S2/S4/S6 USER PASS；S5连播记忆PASS但⚙“循环”上移FAIL；S1、S3 FAIL。0.47.1修正已签名并升级安装/启动（平台确认，[证据](../design/evidence/2026-10-23-reading-fix/README.md)），0.47.1复验S5 PASS，S1/S3于0.47.2复验USER PASS（[ADR-094](094-search-course-rows-and-ai-subtitle-files.md)）；S1–S6全部通过**。

## 决定

- **弹幕/字幕设置调值**：
  - 面板改为单列。可调项显示“名称 ‹ 值 ›”，左右键在固定档位间调整：弹幕字号24–64、透明度25–100%、同屏上限8–64、区域25/50/100%、字幕字号28–72、字幕偏移±60秒（步长0.5秒）。到边界不循环。
  - 调整立即生效并按原路径保存，偏好格式不变。开关项仍按确认切换；原“提前/延后0.5秒”按钮在此构建隐藏，“字幕偏移”行按确认仍归零。
  - 修正：调值必须读取当前偏好对象（保存会替换对象）。
- **Home返回续看**：
  - 播放器关闭时，若页面处于隐藏状态（即按了Home），就在**进程内存**里记下当前普通视频的BV、P、标题、真实位置和时长。只在内存里，不写存储，不含URL或凭据。正常退出或Back则清掉记录。
  - 回到前台后，现有身份校验与页面重建照常进行。第一个产品页面若属于同一身份，就打开整页“继续观看”（上次看到的时间），默认焦点“继续观看 · 时间”，另有“从头播放”。
  - 不自动播放、不出声；身份不同则丢弃。番剧单集与本机队列播放不记录。
  - Home时停声并释放媒体的合同不变。
- **连播偏好持久化**：
  - 写入独立键`bilisofa.playback-continuous.v1.<身份>`（'1'/'0'），读取失败或值异常时回到默认开启。
  - 本机数据清除（`clear()`）一并删除。`PlaybackPreferences`格式不变，0.45/0.46回退读取不受影响。
  - 本机队列沿用自己的连播开关。

## 0.47.1 真机反馈修正（S3/S5，2026-10-23）

用户S3反馈：点字幕仍打开“弹幕与字幕”合并窗口；打开字幕后没看到字幕加载。S5反馈：⚙里焦点进入“循环”后回不到“连播”。根本原因（源码核实）：

1. **S3合并面板**：0.47.0的“字幕”按钮仍调用不分范围的`settings()`，弹幕和字幕各行同在一个面板，首焦点在弹幕开关。
2. **S3字幕状态不可见**：面板只显示元数据/弹幕状态。视频没有字幕轨、需要登录才能读取或读取失败时，用户看不到原因。合成环境里字幕轨可读且会显示；真机上没有字幕的确切原因，0.47.0没有可读的状态文字，无法从源码断定。
3. **S5**：共享面板方向图（`ui/product-panel.ts`）没把⚙列表（`.player-settings`）当单列处理，而是按“工具行”连线，“循环”的“上”指向它自己。0.46.0起就有（P2未覆盖向上移动）。

修正（仅`--product-reading`/`--product-reading-fix`构建）：
- `settings(scope)`分范围：主行“字幕”只显示字幕开关、语言、字号和偏移，标题为“字幕设置”，首焦点为字幕开关，并显示字幕状态（正在读取字幕轨道／这个视频没有可用字幕／需要登录后才能读取／字幕已关闭（有N条可用）／当前语言）；⚙新增“弹幕设置”入口，只显示弹幕各行。偏好格式与档位不变。
- ⚙列表按单列连线，上下互通；无邻居时回到自身。

证据（本地）：`fixes.spec.ts`中S5一条、S3两条（分面板与状态、无字幕时说明），在0.47.1通过、对冻结0.47.0失败。若真机仍看不到字幕，请记下“字幕设置”里的状态文字，用以区分无字幕轨、需要登录和读取失败。真机复验S3/S5待用户。
