# ADR-053：产品直播读取与串行电视内中转

状态：2026-10-20 W04候选；0.21.1列表所请求路径USER PASS，直播两间房间FAIL；[ADR-055](055-runtime-media-fallback.md)替代固定验证范围门禁，以运行时播放/有界降级适配。本地网络/浏览器/打包检查与零售电视验收分开。整包状态见[实施状态](../IMPLEMENTATION_STATUS.md)。

## 决策

- F18读取官方直播首页推荐快照、父/子分区、本人关注房间、开播状态和实际HLS源。源端批次在TV内每页显示4项，不把官方9条关注批次伪装成4条远端分页。列表快照不代表当前仍开播；播放前重新读取。
- 本人关注/私密媒体先用同一保护会话核对Nav UID和直播服务UID。账号失效隐藏私人内容；页面清理等待原生actor，不等待正在触发清理的账号读promise，避免互锁。公共近期消息不带账号cookie。
- `live-read`只读模块与`live-product`媒体模块分开。后者在**同一Emscripten运行时**中先读取API并清空cookie/实际关闭句柄，再启动匿名CDN及loopback中转；不覆盖Module，不依赖嵌套Worker。UI只接收有界DTO及固定本地播放端点，签名CDN地址留在Worker。
- HTTPS、CA/host验证、固定API操作/域名、每请求及内存/并发上限保留。产品中转不沿用W01的40/100秒、128连接、64MiB累计探针配额；TS每段上限8MiB，近期三份清单最多72个源映射，已失效映射不可成为任意代理。
- 选择画质后显示实际返回的qn、编码、尺寸，不按请求标签或广告列表声明成功。实际准备/播放失败按ADR-055有界降级；关闭未确认禁止新源。直播无点播续播、跳转和倍速入口。
- 断流最多两次退避重连；只有持续30秒实际播放推进才重置次数。API拒绝、权限/TLS、格式/上限及关闭未知不自动循环。Home同步发起停播，等待decoder和native双关闭；返回/账号切换后旧回调不复活媒体。
- 直播弹幕为明确标注的**近期消息只读视图**：5秒串行读取、哈希去重、最多12条展示/200键去重，安全文本、不持续自动朗读、不持久化。不发送弹幕；这不是完整WebSocket消息日志，也不按点播时间重播。完整观看设置仍属于F08/F16未完成门槛。

## 一手证据与外部阻塞

2026-10-20读取[官方直播首页](https://live.bilibili.com/)、其房间/分区页面及公开脚本；关注参数和身份结构由[官方直播个人中心](https://link.bilibili.com/p/center/index)公开脚本确认，未读取真实私人列表或执行账号写入。原始响应/脚本保留在仓库外，由`~/.local/share/BiliSofa/w04-live-primary-latest.json`定位。

当前公开响应实际规范化为10个推荐、12个父分区/453个子分区。样本请求qn80，源端实际返回qn250、1280×720 AVC/AAC；近期消息为空。它们只证明当次API/解析，不证明电视声画或真实消息接收。

分区房间列表按当前官方参数、取得新鲜Nav/WBI键后签名，仍为HTTP200/API-352。停止无新依据重试，不进行验证码、客户端身份或代理轮换；分区页面实现及合成检查不算该真实功能通过。UI保留可返回/手动刷新及API码。

HOST检查覆盖生产C固定路由/WBI、TLS/凭据隔离、真实关闭后匿名中转、取消/端口释放、超过旧累计配额与4MiB段、512字节严格Range/TS检查；浏览器使用生产TS Worker、合成native/decoder。门禁和精确源码/工件配对见[测试报告](../TEST_REPORT.md)，集中真机步骤见[当前验收](../CURRENT_DEVICE_TEST.md)。
