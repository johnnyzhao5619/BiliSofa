# ADR-052：番剧追番状态与双向防重复

状态：W04 0.21.1的C所请求PGC详情/选集/声画和私人只读组USER PASS；未提交真实追番写入，真实回查仍待具体授权验收。

## 决策

- F17使用独立`pgc-follow` Worker/C模块，固定Nav、季状态、本人追番/追剧列表和add/del路由。每次先核对本人UID，列表按当前官方空间客户端的WBI协议签名；CSRF只从私密会话读取，POST只提交季ID及CSRF表单。普通PGC只读/播放模块不加入POST。
- 页面先展示季名、季ID、当前状态和拟执行方向，用户另行确认一次。取消/返回/Home不自动发送；API0只代表请求获受理，必须另行读取季状态，才能说明当前是否追番。网络、取消、解析或关闭未确认均不能证明写入没有发生。
- 沿用schema1持久日志，新增`bangumi-unfollow`方向，原`bangumi-follow`及其他旧记录保留。同一账号/季的任一方向未知时，两个方向都禁止发送。
- 专用`reconcileBangumi`在同一目标锁内只读查询并原子核对两个方向；只有真实状态允许把可逆追番方向的旧confirmed改为not-applied。投币、三连、云进度及旧一次性授权不适用，不清除或重发。
- 撤销账号权限时先持久保留未知结果，再隐藏私人页面。页面销毁仅等待native请求实际关闭，不等待正在触发该销毁的账号/UI promise，避免登录失效时互相等待。关闭ACK缺失则禁止复用。

## 证据及限制

协议来自2026-10-19[官方季页面](https://www.bilibili.com/bangumi/play/ss28747)及[官方空间页面](https://space.bilibili.com/2/bangumi)引用的公开脚本；原始文件仅在仓库外私密目录，哈希索引为`.local/w04-pgc-follow-primary-summary.json`。该协议核查未读取私人账号列表或执行线上POST；之后用户已确认C私人只读组，线上POST仍未执行。

合成单元、真实生产C的本机TLS表单/方法/WBI/失败关闭检查、生产TS Worker的浏览器确认/未知回查/取消/账号隔离见[测试报告](../TEST_REPORT.md)。这些不能替代真实账号回读及零售电视验收；统一随W04提交，具体写入仍由用户确认对象和方向。
