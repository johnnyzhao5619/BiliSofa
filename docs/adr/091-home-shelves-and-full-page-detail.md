# ADR-091：首页货架、焦点放大与整页详情

2026-10-23；F02/F05/F06/F07、R05/R15、U5。用户确认第二批E2（货架）与E4（先进详情）。仅在`--product-polish`（0.46.0）构建生效。状态：**0.46.0已签名并升级安装/启动（平台确认，[证据](../design/evidence/2026-10-23-polish/README.md)）；用户所请求P1–P7 USER PASS**。

## 决定

- **首页货架**：
  - 继续观看（有记录才出现，带进度）→ 为你推荐（登录）→ 热门视频 → 排行榜，末尾“浏览分区”。
  - 每行最多12张卡，横向浏览，行尾“查看更多”。
  - 热门每页4条，取2页（2次请求）；排行榜1次请求后本地分页（12张）；推荐1次请求。
- **请求控制**：
  - 货架用自己的内容运行时，与网格分开。该运行时开始新读取会作废进行中的读取，所以各行串行加载：首行在挂载时加载，下一行在焦点进入上一行时加载，最多领先一行（0.65.0起由[ADR-117](117-ranking-session-refusal-and-row-order.md)取代：上一行读完即读下一行，不等焦点）。
  - 每行独立失败，显示“重试”，不影响其他行；没有自动重试，避免触发API -352/HTTP 412。
- **“查看更多”**：同一页面切到原有连续网格（保留原页码/缓存/来源切换），焦点落在第一张卡。Back回到原行的“查看更多”（`frameBack`页面级返回钩子）。“浏览分区”打开原分区选择。
- **上下移动**落在相邻行的相近列（静态邻接）；继续观看行向下进入第一行。
- **卡片第三行**显示播放量（已有`PopularCard.views`，如“1.2万播放”）。
- **焦点放大**：聚焦卡片放大1.05倍并加阴影，只用`transform`/`box-shadow`。“减少动画”时只保留描边。
- **整页详情**：
  - 大封面、标题、UP主、时长、播放量，主按钮“播放/继续观看”，加上“加入本机队列”。
  - 多P视频有界地读一次详情，显示分P列表（P号、名称、时长、已看位置），选某P直接播放。
  - 读取可取消；详情关闭前等待读取与访问对象关闭，再打开播放器，不与播放器并存。
  - 播放器打开后会再读一次详情（本批未做结果复用，多一次请求）。
  - 计划中的“分区精选”行改为页尾“浏览分区”入口，避免默认替用户选分区。
- **不做（2B，需新来源与授权）**：简介、发布时间、点赞数、相关推荐、详情内UP头像与关注、进度缩略图。界面不显示占位假数据。
- **继续观看封面**：本地记录不含封面引用，本批未接入；保留进度条与后备图。

搜索页仍用原网格。投屏、F11、ADR-088键位不变。

## 证据

与[ADR-090](090-player-main-row-settings-and-next-up.md)同一构建与测试（`tests/product-polish-ui/home.spec.ts`：货架、单行失败隔离与列记忆、查看更多/Back、焦点放大与减少动画、整页详情与分P直接播放）。真机P5（货架）、P6（整页详情分P）USER PASS。
