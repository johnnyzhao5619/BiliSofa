# ADR-040：匿名 UP 主搜索与搜索附带的视频预览

2026-10-18，W03/F03，内部0.10.0；承接ADR-039。完整UP主页、投稿列表与分页仍属F04后续工作。

## 决定与依据

沿当前匿名nav→WBI固定查询协议，新增唯一固定类型`search_type=bili_user`，不开放调用者自选类型、URL、UID端点或凭据。官方公开搜索接口的本机实际响应为HTTP200/API0、四条bili_user结果；mid为数字，uname/fans/videos和res为附带摘要，res含0或3条视频，play可为十进制字符串。原响应只留仓库外，生产解析/IPC验证四UP、三项附带预览通过。此为HOST资料，非电视验收。

复用search Worker/C，但请求/结果分为`public-video-search`和`public-user-search`两个严格合同、各自错误前缀search/up。固定C包装选择video或bili_user；公开材料获取、WBI编码、CA/TLS、nav16KiB/查询512KiB、4/8秒网络期限、20秒父读取/12秒关闭期限均保持。停止消息必须匹配操作与Scope，原生闭合后才读堆、下一事件边界再执行查询，无自动重试或未签名回退。其他四类原生模块保持。

## 数据与交互

- 每页最多四UP、最多十页；UID作为身份/焦点键，不按同名合并。只接收安全整数UID、纯文本名称、非负整数粉丝/投稿数，不接收链接、头像、签名或账号状态。
- 每UP最多一条搜索附带预览，保持原120字符标题/48字符作者；四卡最坏有效Scope与文本/数字仍在原4KiB IPC内，不扩大消息预算。没有res时只表示本次搜索未附带预览，不能推断UP没有投稿。原响应其余预览不进IPC。
- 首页“搜索UP主”沿现有首字母输入/候选；确认关键词才查询。结果两列显式邻居、前后页/更换词/用户明确重试；摘要展示UID与统计，预览接原媒体owner。Back依次媒体→摘要→原UID卡→UP搜索入口；加载可Back，Home或身份失效取消读取/丢弃晚到结果。
- 历史仍是按当前身份隔离的纯关键词，不迁移schema或恢复已关闭的记录开关。UP结果页的历史选择保持UP语境；首页原历史入口仍默认视频搜索。

## 验证边界

合成浏览器可证明类型、焦点/取消/返回/错误恢复和已有媒体装配，HOST TLS可证明固定类型/签名/目的地规则；两者不代替零售电视真实搜索或声画。只请求一组新增UP搜索/翻页/摘要/预览短播Back，失败即停止，不重跑已通过的视频搜索、历史、Home、扫码或投屏。无账号写入、新权限、依赖安装或外部常驻服务；完整F03/F04/W03及v1.0.0继续开放。
