# ADR-049：私人列表中的显式本机入队

2026-10-19，W03/F05，内部0.19.0。0.18.1用户确认当前网络恢复及原本机队列最小组通过；旧0.18.0失败和原因未确认保持，不重复调查或原组。

## 来源和合同

复用ADR-044/045/046归档的官方playlist/history脚本：watchlater规范化从行级bvid读取；收藏media_list从bv_id读取；archive历史从history.bvid读取。已再次读取归档源码相应结构，不执行外部脚本、不复制其它客户端身份或密钥，也不从URL/aid/文件名推造BV。

三类显示DTO只新增可选、严格校验的普通UGC公共bvid。原生凭据/资源ID/夹ID/游标仍不进UI/队列；library Worker闭合结果和页面再次校验该字段。源端缺失或异常BV只禁用入队，不使原只读卡片整页失败；IPC里带错BV/非UGC BV/额外字段仍拒绝。无新端点、账号写入、SDK、权限或原生编译，24项native运行文件保持。

## 用户操作和存储

各摘要保留Back为初始实际焦点，新增“加入本机队列 · 首P”。稍后再看仅源端正常的普通UGC，历史仅首P或未指明分P的普通UGC，收藏仅有有效BV的普通UGC可以入队。番剧/课程/直播/未知类型/缺BV，以及历史明确非首P时禁用并说明。仅获用户显式点击后，将BV和标题复制到当前已核对账号的固定普通KV队列；不复制云端进度、Cookie、媒体URL或游标，不修改源端稍后再看/收藏/历史。

该存储是电视本地普通数据而非加密；界面明确“仅加入当前账号的本机队列，不修改云端列表；播放使用游客首P”。当前入队不证明内容能匿名播放、会员/私人内容权限或可用性，播放仍沿ADR-048重新取源并服从真实结果。暂不支持的类型/分P和完整F05/W04仍保留。

显式入队采用现有去重/64项上限/写后回读/未来schema拒绝策略，无静默清空或自动批量导入。按钮归摘要ResourceOwner：Back/Home/账号切换后旧节点的点击不可修改旧或新队列。账号删除既有队列清理屏障保持；入队不开始播放。

## 验证和边界

本地核对三类官方字段映射、缺失/非法BV降级、严格IPC、UGC类型限制；真实生产Worker/adapter的合成流程覆盖三类显式入队、去重、其它类型禁用、历史非首P禁用、旧摘要点击失效和账号隔离。复用旧队列UI回归，不重跑W01声画或登录矩阵。实际TV只安排新增入口的入队/返回与当前身份队列核对，不要求播放、重开、切号或任何云端写入；空列表不要求新增私人内容。
