# ADR-038：独立匿名热搜读取与既有搜索复用

2026-10-18，W03/F03；内部0.9.0，不改变单一完整v1.0.0范围。

## 决定

新增热搜入口，经统一TvShell模态、HotSearchWorker和单独hot-search.c读取固定 `https://s.search.bilibili.com/main/hotword`。无调用方URL、请求头、Cookie或账号字段；不复用身份Worker。新增域名只用于此编译期固定GET，不构成任意Bilibili域名访问许可。沿既有共享GET的证书/主机名校验、CA、无重定向、4秒连接/8秒总期限与16KiB头预算，体预算进一步限64KiB。没有新SDK、权限、依赖或外部常驻服务。

原始响应仅在Worker内解析。最多10项、排名1–10严格递增、关键词沿现有32码点/128字节合同，显示文字80码点/320字节；重复、非法或过大数据拒绝。只接收goto_type=0的搜索项，忽略图标、目标地址、追踪参数和其他元数据。返回规范化rank/keyword/label，页面仅textContent显示；显示文字和搜索词分别使用，不从显示名或跳转URL猜查询。

每次入口显式读取一次，六词一组在内存分页；刷新必须用户点击，无自动轮询或失败重试。列表不进缓存或诊断，打开/翻页不写搜索历史；选择后先关闭模态、等待原生关闭再交给既有视频搜索，沿当前身份历史开关。既有search.http_412只保留手动重试，不因热搜加入身份/UA伪装或绕过。加载/错误均保留返回，刷新清除旧列表；Back/Home/账号切换使owner失效，拒绝晚到结果。未确认原生关闭仍阻止复用。

新模块随同一WGT打包；原identity/native/catalog/search四类16项保持，热搜单独四项有来源/固定目标/CA/包门禁。包版本0.9.0、应用ID BiliSofa01.TV不变，已有普通设置和保护会话不迁移/清除。

## 依据与退出条件

官方主机的[公开响应](https://s.search.bilibili.com/main/hotword)于2026-10-18可读；本机一次匿名HTTPS HTTP200/API0、4828bytes、生产解析器输出10项，原始响应和热词不写入记录。此事实不承诺接口长期支持、不证明TV读取，也不是412根因证据。

本地验证需覆盖有限合同/解析、固定TLS请求/无凭据/不跟随重定向/预算、真实Worker与合成C的焦点/分页/选择/开关/错误/取消、包固定端点门禁。真机只做一次新增功能组：热词显示/两组翻页/Back回入口，再选择一个词，核对进入匹配视频搜索或其明确错误；失败不反复重试，不播放。既有历史组已通过，不再重复。完整UP/PGC/live搜索及W03其余要求保持开放。
