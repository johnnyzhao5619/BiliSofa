# ADR-104：分区读取使用电视运行时自身的User-Agent，所有视频入口共用详情页，读取失败后焦点不丢

2026-10-23；F02/F04、R05/R15、U5。接0.51.0真机结果。仅在`--product-up-fix`（0.51.1）构建生效。状态：**0.51.1已签名并升级安装/启动（平台确认，不清数据）；V1 FAIL，导航与关注页直达卡 PASS，V2②部分；“单靠User-Agent即可”的结论作废，见文末与[ADR-105](105-signed-public-reads-pacing-and-local-detail.md)**（[证据](../design/evidence/2026-10-23-up-fix/README.md)）。

## 0.51.0真机结果

- **V1 FAIL**：第一页的分区（试了6个）都显示“内容暂时无法加载。可重试或换个栏目”；另外，从分区回不到其他位置，导航失效。
- **V2**：
  - ① 搜索UP进入UP主页：PASS；
  - ② 只有首页和搜索进入的是完整详情页，“我的”“关注更新”“继续观看”仍是旧面板；偶尔被B站限制，过一会儿会恢复（即限频提示）；
  - ③ 翻页、播放、返回：PASS；搜索视频结果与首页详情一致：PASS。
- 关注页直达卡：用户未报告。

## 原因

- **分区**：本机限时只读核对。同一个分区，交替使用三种User-Agent，每次间隔4秒、各请求一次：
  - 原生自定义标识`BiliSofa-W01-Probe/0.0.15`：-352；
  - 在Tizen字样后加`BiliSofa/0.51`的串：-352；
  - 真实的Tizen电视浏览器User-Agent：code 0。
  - 全站榜（rid=0）用原生标识也正常。
  - 0.51.0证据中“本机匿名14个分区均可读”用的是浏览器形态的User-Agent，没有复现电视实际发出的请求，那条结论作废。
- **导航**：合成UI按设备上的路径复现了两处问题：
  1. 在网格的“分区”按钮上反复切换分区后，按“重试”，焦点会落到`BODY`，下一个按键直接跳到导航栏的“首页”；
  2. 没有卡片时，“重试/上一页/下一页”向上指向首页并不存在的`search-input`，按上键没有反应。
- **详情**：“我的”（历史、稍后再看、收藏）、“关注更新”“继续观看”各有自己的旧面板，没有简介、UP头像、分P、UP主页。

## 决定

- **分区与UP主页读取使用电视运行时自身的User-Agent**：
  - catalog Worker把`navigator.userAgent`原样作为`--ua=`传给原生，只在TS与原生都校验通过时使用：8–400个可打印ASCII字符，拒绝CR/LF等控制字符。
  - 新入口`catalog-ua.c`把冻结的`catalog-up.c`原样包含进来，只把`CURLOPT_USERAGENT`的值换成传入的串；没有`--ua=`时仍用原标识。链接到新目录`build/catalog-ua`，`catalog.c`、`catalog-up.c`、`probe-guest.h`都不变。
  - 这是电视浏览器引擎自己的标识：不伪造浏览器指纹参数，不冒用其他客户端；其他原生模块不变。
- **焦点**：
  - 读取失败后，若焦点在`BODY`、已隐藏或已禁用的元素上，移到“重试”；
  - 没有卡片时，翻页/重试按钮向上回到当前选中的来源按钮。
- **所有视频入口共用详情页**：
  - “我的”的历史、稍后再看、收藏，以及“关注更新”“继续观看”，都打开与首页相同的详情页（简介、事实、UP头像、分P、UP主页），并保持各自的续播分P：主按钮为“继续观看 · P2 0:03”，入队为“加入本机队列 · P2”。
  - UP名缺失时，由详情读取补上。
  - 本机队列与本机记录仍用原面板，因为它们有队列和删除操作。

## 不做

- 不用`Mozilla/5.0`之类的通用串伪装，不改其他原生模块的标识，不对限频自动重试。

## 证据

- 原生主机测试`tests/native/catalog-ua.test.py`，17条：继承catalog与catalog-up的全部检查；所有请求都核对User-Agent，没有`--ua`时为原标识；传入的电视串原样使用；非法串（过短、CR/LF、控制字符）不会进入cURL。
- 单元：运行时User-Agent校验。
- 合成UI`tests/product-up-fix-ui/fix.spec.ts`，4条：
  1. 仿B站“无运行时User-Agent就-352”的fixture下，分区能加载；
  2. 按设备路径反复切换分区后按“重试”，焦点留在“重试”，上键回到“分区”；
  3. “继续观看”打开共用详情页：P2续播，读取后显示UP名和“UP主页”；
  4. “我的 → 云端历史”打开共用详情页，并在P2入队。
  - 4条对冻结0.51.0全部失败。
