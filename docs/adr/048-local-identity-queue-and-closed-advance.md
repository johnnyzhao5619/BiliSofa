# ADR-048：本机身份队列与确认关闭后的换项

2026-10-19，W03/F05/F07本地部分，内部0.18.0，BiliSofa01.TV。0.17.0关注更新导航最小USER组通过，具体空/非空/分页分支未明；不重复。

## 本批行为与边界

普通热门/排行榜/视频搜索播放页可“加入本机队列”，按BVID去重、最多64项，首页进入本机播放队列。队列有四卡分页、上/下移、移除及确认清空，按游客或已核对账号固定分区持久化；删除账号时删除该账号队列，不改变其它身份、保护会话或未知写操作日志。损坏/未来schema不静默覆盖，写后回读确认，失败明确提示。

独立普通KV键`bilisofa.queue.v1.<owner>`，schema1仅continuous/有限BVID与安全标题。没有Cookie、云端游标、媒体URL或原始账号响应；不修改既有local-profile v1、保护存储格式或防重放journal。进入/重开队列不自动播放；“播完自动下一项”默认关，显式启用后只影响随后用户开始的本次固定快照。普通本地数据不声明为加密存储。

新本机队列播放沿已验证GuestPlayback→MediaSession→AVPlay路径：只取匿名360P首P，每项重新获取源，既有15分钟内部媒体lease继续存在。首项可按既有本地续播提示显式开始；后续项从头。该实现不把当前电视账号Cookie交给匿名网络，不声明可播放私人/会员/PGC内容，云端私人列表入队、全内容队列/连播及长播放仍分别在F05/W04保留。

## 资源所有权

packages/media/queue管理固定快照和代次，UI不直接访问AVPlay。手动下一项/自然结束换项前必须等待旧MediaSession实际decoderClosed+transportClosed；SDK close调用或Worker终止均不代替这两个事实。关闭未知则停止并保持unknown，后来的成功不能改写旧unknown；取源/播放失败停止，不跳过、不删除失败项或无限重试。

Back/Home/换号先递增代次并关闭当前资源；等待ACK期间取消后不允许创建新播放器，旧完成回调不能触发下一项。队列父层和媒体模态各有owner，沿TvShell单一焦点/返回栈；播放背景inert层隐藏绘制仍保留。每项LocalPlayback只保存所属身份真实事件进度，无云进度写入、稍后再看/收藏增删。

## 验证与退出

本地schema/容量/去重/身份隔离/未来格式/回读不确认，串行关闭、迟到完成、取消与unknown门槛；实际Worker/AVPlay适配器的合成界面组合及旧媒体/本地/账号回归。包/源码匹配与TV最小组另记，不将合成自然结束当作真机连播通过。TV仅检查新入队/重开、一次手动下一项及Back，首项足够短时可补自然换项；不重做W01矩阵。完整F05/W03及W04真实连播保持开放。
