# ADR-074：统一搜索工作区

2026-10-21；U2/R15，F02/F03/F04/F17。独立0.32.0开发候选`dist/product-discovery-app`，属于同一产品的内部开发批次。电视保持0.28.0；不生成WGT、不签名/部署，不执行真实账号POST。0.28–0.31冻结工件保留。

## 行为与边界

搜索共用一个关键词和视频/UP主/番剧影视三个类型；首字母输入、热搜、当前身份的历史均回同一结果页。类型分别记页码，换词回第一页；四张卡片、分页、空/错误和手动刷新共用布局。类型选择、导航和结果使用实际DOM焦点和现有InputRouter/FocusRouter，无新增页面键监听。

普通视频详情支持本机继续/从头、入队，先关闭详情再启动原VOD工作区；UP仅展示搜索提供的统计及附带视频预览，不冒充完整主页/动态。番剧摘要进入已有季/集工作区，权益和播放源仍由既有适配器核对。封面仅复用ADR-072的受限公开图片适配器，源未提供时用类型文字；外部内容以textContent显示。直播不进入类型列表。

新关键词/类型递增视图代次，取消旧Session并等待三条既有Worker的关闭确认，再启动新读；原生关闭未知则禁止继续复用。迟到结果不能覆盖新类型、导航或弹窗焦点。相同类型翻页失败保留上一页及可用恢复入口；新类型失败不显示其他类型旧卡。Home释放请求/图片，返回后按当前身份重新读取；不清除本机位置、队列或未知写入日志。账号切换清除搜索内存，历史仍按身份隔离。

弹窗容器层级置于固定导航上方；输入/热搜/历史采用同一产品配色。此修复不改变AVPlay调用或媒体资源所有权，真实电视合成层仍待整包验证。搜索读/API错误保留经过合同验证的末尾码；不以重复请求绕过风控，不新增自动无限重试。

## 验证与剩余

验证结果、构建身份和合成截图统一见[证据索引](../design/evidence/2026-10-21-u2-search/README.md)与[测试报告](../TEST_REPORT.md)，不将桌面结果写成电视通过。首次合成检查中的Home用例错误预期与历史选择器已修正，失败日志保留；截图复核发现并修复导航遮挡输入层的问题。

[布局](../design/U2_SEARCH_LAYOUT.md)是实现依据。U2的番剧/关注入口、账号/设置仍需产品化；完整UP/动态与分区来源阻塞继续保留。U3–U5、真实TV朗读/远距/图床/性能与最终打包验收保持OPEN，不为本内部构建安排微测试。
