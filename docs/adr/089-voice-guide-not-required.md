# ADR-089：Voice Guide不再作为需求或验收门槛

2026-10-23，依据用户在0.45.0 R1–R6全部通过后的指示：“R7请移除该项目，这不是需求”。

## 决定

- Voice Guide（三星TV朗读）**不是当前产品需求**。它从验收门槛、真机清单和发布条件中移除，包括ACCEPTANCE跨领域门槛、PRODUCT_CLOSURE T7、TV_UI/TV_PRODUCT_DESIGN的朗读检查，以及第一批计划的R7。状态记为“用户移除（非需求）”，不是PASS，也不是FAIL。
- 现有可访问性实现保留，不为此删改代码：
  - 按钮、卡片的`aria-label`；
  - `role=status`只在文本变化时写入；
  - `config.xml`中的`use.voiceguide`元数据。
  这些只是无成本的工程基础，不承诺朗读质量，不安排测试，也不作为任何功能的通过条件。
- 其余可用性门槛不受影响：远距可读、焦点可见、减少动画、长中文/深列表、弱网/空态/权限提示。
- 历史记录（W01–W02探针、ADR-003/059/070–077等）中的Voice Guide表述保留原样，作为当时的范围记录，不追改。

## 影响

0.45.0第一批遥控快改的所请求真机组为R1–R6，全部USER PASS；R7撤销。R15与T1–T8其余条件不变。
