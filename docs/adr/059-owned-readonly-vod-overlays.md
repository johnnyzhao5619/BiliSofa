# ADR-059：绑定实际分P的只读字幕与弹幕

状态：2026-10-20，W05第一完整模块候选0.22.0；本地门禁及A–D所请求真机组通过；用户另报弹幕跳动/控制栏问题，后续修复见ADR-060。范围为F08/F09/F16及对应F12设置，评论和保留互动另批实施。

## 读取与所有权

独立`overlay-worker`/`overlay-read`运行在电视内。生产源Worker通过一次性MessagePort直接传递当前catalog对应的私有CID；主线程只持有不透明catalog ID。每次读取重新核对公开视频/剧集与CID，失配取消，不能把另一分P的叠加放到当前媒体。账号代次、请求取消和原生实际close确认沿用资源所有权规则；关闭未知时禁用该读取lane，不冒充已释放。

2026-10-20核对官方页面引用的[播放器脚本](https://s1.hdslb.com/bfs/static/player/main/core.147ce847.js)：字幕元数据使用`/x/player/wbi/v2`，分段弹幕使用`/x/v2/dm/wbi/web/seg.so`。自有WBI实现及有界protobuf读取，不打包官方脚本，不降级到旧未签名接口。官方原文/hash和匿名请求留仓库外`w05-primary-latest.json`指向的目录；不是稳定公开API承诺。

字幕URL仅允许固定hdslb字幕主机/目录，使用匿名独立handle，不携带账号Cookie或媒体Range，不跟随重定向。原始URL/凭据/私有CID留Worker；UI接收规范化轨道/时间/文本。普通弹幕支持滚动/顶部/底部；BAS/代码等模式不执行。正文、条数、分段缓存、请求队列、堆和期限均有上限；TLS验证不变，无新增权限/外部服务/账号写接口。

## 播放、偏好与恢复

叠加按AVPlay真实媒体时间绘制，暂停不推进；跳转、倍速及换P重建窗口，旧请求不能覆盖新内容。读取失败与空数据区分，允许手动重读，不自动停止视频。Home先关闭解码器并清除绘制，随后等待可选读取实际关闭，避免其延迟挡住停声。

观看设置按固定身份独立保存：弹幕开关/字号/透明度/密度/区域/关键词；字幕开关/字号/语言/偏移。早期schema1缺language时仅归一化为auto；损坏/未来schema不自动覆盖。过滤词使用本地首字母候选，不是弹幕输入/发送功能。文本层不拥有焦点、键盘或Voice Guide朗读；控制/设置仍由单一TvShell管理，字幕避让控制栏。

## 证据边界

主机匿名请求及解析、HOST TLS/C边界、生产TS/Worker浏览器合成流程分别记录于[测试报告](../TEST_REPORT.md)。本地检查不证明完整电视性能/Voice Guide；0.22.0用户已确认A–D请求组通过，两处显示缺陷另行补验，不扩展为全媒体/语言矩阵通过。评论/账号写入及W04迁入项保持OPEN，直播维持ADR-057延期。
