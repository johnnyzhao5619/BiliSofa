# ADR-042：匿名直播间搜索与房间摘要

2026-10-18，W03/F03，内部0.12.0。承接ADR-039/040/041；0.11.0番剧结果/摘要/Back最小组USER已通过，不重复原组。

## 来源与决定

固定[公开WBI搜索路由](https://api.bilibili.com/x/web-interface/wbi/search/type)增加唯一类型`live_room`。本机匿名“音乐”查询取得nav HTTP200、搜索HTTP200/API0/3773bytes，四条房间、pagesize4、总91/23页；程序仍限定最多十页。实际字段有roomid、uname/title、cate_name、tags、online和live_status，图像/地址/短号/关注数等不进入结果。原响应SHA256 `f6588c94d7c53aab7c3f76fabc95e8834d5ecc0ae816f39a76db46eabbdaf054`，生产解析四卡/noMore=false/981bytes IPC通过；原JSON仅私密保存。本机独立请求与生产解析不是生产C外网或TV证据。

使用第四个严格操作`public-live-search`/`live-search-wbi`。C内部只允许四种固定类型video、bili_user、media_bangumi、live_room，未知类型不发请求；不开放URL/任意类型/直播源/账号凭据。公开nav→真实关闭→材料校验→下一事件边界取消检查→WBI查询、noExitRuntime、TLS/CA、无Cookie/redirect/代理、nav16KiB/搜索512KiB、4/8秒网络与20/12秒父端期限保持。仅重建search模块，其他16项native不改。

## 数据与交互

- roomid为安全正整数转字符串，作为身份/焦点键；忽略short_id等别名，不按同名合并。每页四条/最多十页，重复房间拒绝，非法数据只有固定字段错误码。
- 标题120、主播48、分区32、标签32字符、人气为非负安全整数，状态仅live/unknown；四卡最大有效Scope满足原4KiB IPC。online展示为人气，不解释为并发观看人数。
- 状态来自搜索快照，不持续查询或假装是播放器状态。已核对的live_status1显示直播中；缺失或0/2显示未确认，不在缺少本轮依据时自行宣布轮播/退出等能力；其他非法标志拒绝。0/2的更细语义及实时房间状态归实际媒体流程后续核查。
- 首字母输入明确确认后搜索，结果两列方向邻居、前后页、更换关键词、显式重试及只读房间摘要；Back摘要→原room卡→直播入口。历史沿当前身份的关键词/开关，直播页内历史选择保持直播语境，无schema迁移或账号事实。
- Home/身份变化取消owner并丢弃晚到消息，加载可Back；错误清除旧卡，HTTP/API/格式/空结果分开，不自动重发。

## 退出条件

只新增直播间搜索/摘要，不装入直播播放按钮或新的媒体网络目标。完整直播播放/状态刷新/恢复归W04，F03完整矩阵、F04及其余W03–W07不由本批关闭。只请求一次“音乐”结果/前后页/摘要/Back人工组，失败即停止；不重复已通过的视频/UP/番剧、账号、投屏或声画。没有新权限、依赖/SDK安装、账号动作、外部服务、提交/推送或发布。
