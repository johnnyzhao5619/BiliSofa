# ADR-078：可逆互动的独立能力与一次确认

2026-10-22；F11 / W05 / U4-R03。承接ADR-068，恢复点赞、关注UP、收藏夹增删、稍后再看；F14投币/三连保持暂停。0.36.0是同一应用的内部候选，不代表U4或完整产品完成。

## 合同与行为

- 身份与视频目标是必需读取；点赞、投币计数、关注、稍后再看、收藏夹、余额分别有可用或未确认状态。同一关系响应分别解析点赞与投币字段；投币/余额错误不使点赞不可用。
- 未读字段必须为`null`并携带白名单`unavailable`阶段码，不能用false、0或空收藏夹冒充成功。错误只允许固定阶段/错误枚举，不传响应、地址、UID或凭据。必需读取错误也保留identity/video等阶段。
- 只有收到原生完成响应的网络失败、或响应解析/权限错误可以降为局部不可用；未完成超时、begin拒绝、取消、登录失效及清理未知终止整批，不叠发原生请求。TLS、固定目的地和响应上限保持。
- 大屏入口为“点赞 / 关注 / 收藏”，面板展示四类可逆能力。不可用项禁用并给出原因；选择后展示当前视频、UP或指定收藏夹、增删方向，默认聚焦取消。Back/Home/换源不提交；视频由原播放owner继续持有。
- 提交前持久保留意图，重新核对本人、目标和该操作的实际基线，最多POST一次，再独立读取。局部失败不能伪造回查成功。unknown只允许读取，不能补发；旧投币unknown不因可逆状态改变而解除。
- 产品UI不显示投币/三连动作，`InteractionRuntime`默认拒绝它们。原实现/合成回归保留，未恢复真实F14授权。
- 互动lane一旦收到登录失效即丢弃自身凭据并撤销旧grant，不能继续使用该lane。整个应用的失效重登/原目的地恢复仍归R06，不能用本项代替。

## 兼容和证据

旧完整state及schema1日志仍可读取；新局部state只给相应操作保留已有证明，journal拒绝该操作自身基线缺失。旧retained journal及W01未知记录不迁移、不清除。新日志的null扩展会使旧版本读取器安全拒绝并锁写，不能宣称旧版互动回退兼容；U5仍需验证整体升级/回退。

独立`--product-interactions`生成0.36.0，不覆盖0.28–0.35工件；原生C/固定路由沿用，JS Worker及合同重新配对。检查使用合成账号/响应/媒体；不执行真实账号POST。旧`interaction.invalid`因缺阶段证据仍不能唯一归因，新包只读真机结果及后续具体目标授权验收均OPEN。见[本轮证据](../design/evidence/2026-10-22-interactions/README.md)。
