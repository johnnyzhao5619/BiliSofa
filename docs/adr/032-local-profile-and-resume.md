# ADR-032：按身份隔离的本地设置、续播与有界诊断

日期：2026-10-18；状态：W02实现决定，F07/F12/F13。云端续播、完整设置和新包真机验证未完成。

## 边界

- 登录cookie继续只进KeyManager固定槽。普通LocalProfiles只接受schema、两项已生效偏好和有界的普通视频首P位置；不接受Cookie、标题、地址、媒体token或任意额外字段。访客与每个已选择/核对的账号使用固定独立分区，不在切换、登录或恢复时相互迁移。
- 单分区最多64条记录、16KiB JSON；BVID、part=1、毫秒位置/总时长与更新时间都严格验证。损坏/未知schema不自动丢弃、覆盖或假装默认已保存；用户确认后只删当前分区。存储拒绝、忽略写入/删除或回读不一致均反馈未确认。
- 本地续播提醒只控制是否询问恢复；位置仍会按实际观看保存。遥控跳转步长为5/10/30秒，实际作用于游客播放器及投屏遥控操作。未实现的画质/弹幕/字幕/连播设置不提供虚假控件。
- 播放页持有创建时的固定分区，而不是在回调里查询可变的当前账号。普通游客源仍匿名联网，但本地观看记录归当前选择身份。每五秒最多渐进保存一次，Back/Home/错误关闭前同步保存最后实际位置；结束事件在PlayerCoordinator清零前观察，真实自然结束清除对应书签。关闭后的观察和已离开页面的旧控件不能再保存。
- 从本地位置恢复需用户明确选择“继续观看”或“从头播放”。原生源仍重新取得/检查，准备后串行seek完成才play；成功seek不制造目标time tick。总时长在准备完成、播放前缓存，避免刚起播就返回时漏存，并避免在busy或结束清理阶段额外读SDK。无有效时长/位置不伪造书签。
- 投屏媒体目前没有可靠BVID/分P身份，不将其临时URL或手机账号猜成电视书签。投屏本批仅消费跳转步长；完整投屏/内容本地接续仍归W04/W06。
- 确认移除账号时先完成视图/媒体关闭，再核对对应本地分区删除，最后移除受保护凭据。本地清除未确认则保留账号条目，提供原入口重试；其他账号、访客和两份W01未知写意图不动。保护凭据删除未知仍按既有账号安全合同处理。

## 诊断

AppDiagnostics只收录固定area/code和单调序号，内存最多32条，进程退出不保留。没有自由文本、账户ID、昵称、BVID、播放位置、地址、URL、Cookie、native原文或设备ID入口。设置页按每页8条展示，真实DOM焦点/Back沿用唯一TvShell；不需要编辑器、外部上传或额外键监听。它是应用级结果摘要，不替代W01原生底层取证、真实设备性能或完整F12故障恢复。
