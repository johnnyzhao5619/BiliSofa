# ADR-118：0.65.1 公开开源版本基线

日期：2026-10-26。状态：用户选定公开版本并已授权公开执行；结果见文末发布记录。关联：F01–F20 / W07 / R14。

## 背景与决定

用户指定完整提交 `e7bc3740e0fed2f9b2c89f9a83755398fa11faf7`、版本 0.65.1 作为正式对外的开源版本，并要求调研最佳实践，重写 README、许可说明和安装指导，同时评估 Bilibili 用户协议。

该决定更新此前“只有完整 v1.0.0 才对外”的发布定位：**0.65.1 可作为独立明确的公开版本准备发布**。不为本次发布虚构 v1.0.0 完成，不关闭既有 BLOCKED / PAUSED / 条件未验证项，不改变直播、双账号及只读讨论的既有决定。其他内部工作批次仍不是独立产品发布。

## 身份与交付规则

- 软件源码和 v0.65.1 目标 tag 固定到上述提交；本轮新文档是该提交之后的文档变更，不修改软件版本、实现、签名、权限或设备数据。
- 新文档单独提交后记录其 SHA；软件 tag 若留在旧提交，发布说明应说明两者关系，并附带固定文档快照 / 许可补充。不能让 tag 悄悄指向后续提交。
- 若将更新后的 THIRD_PARTY_NOTICES 嵌入重建 WGT，该包不再是旧冻结工件；必须有新的来源与哈希。当前保留现存工件，不在文档轮重建覆盖。
- 公开安装路线为未签名 WGT + 使用者本地 Samsung TV 证书签名；私密签名包不作为全用户通用包。
- 标准 MIT 不变，新增许可边界说明；第三方组件和平台 / 内容 / 商标权利不改标 MIT。服务风险见[协议评估](../BILIBILI_TERMS_RISK.md)。

## 发布条件与证据

R14 按[发布清单](../RELEASE_CHECKLIST.md)跟踪 0.65.1 的公开材料、历史 / 附件敏感信息、许可和来源。完整 v1.0.0 的产品验收继续由[收口台账](../PRODUCT_CLOSURE.md)跟踪，不把两者混作一个通过状态。

本轮落实文档准备，不进行源码提交、tag、推送、可见性调整、GitHub Release、SDK 安装、应用测试或设备部署。用户的发布意图已记录，后续不应再次把 0.65.1 的版本选择当作未作决定；远端执行与待审材料的实际结果需单独记录。

## 后续构建授权与结果

同日用户要求加入作者学习 / 测试、无盈利行为与权利联系 / 愿下架声明，构建下载版本并研究快捷安装及用户输入域名方案。用户确认之后将自行公开 GitHub 仓库，权利联系使用公开后的 Issues；本轮不改变仓库可见性或上传公开附件。

本轮按原始提交建立独立源码目录，重建 Web 层并复用来源校验通过的原生模块，运行原有打包门禁；得到与冻结未签名 WGT 相同的 SHA-256。不是干净机器全原生重编译，不增加设备 / 用户通过；没有应用测试、签名或部署。当前文档与下载配套材料单独固定文件摘要，不嵌入旧包。用户输入域名仅作[研究](../research/user-supplied-site-risk-2026-10-26.md)，不新增规避门槛。

## 后续公开授权（2026-10-26）

用户随后明确授权将仓库设为 public、编译可下载包并提供便捷手册。允许执行所需代码 / 文档提交、推送、精确软件 tag 和 Release；不需要再次询问上述授权。原 0.65.1 tag 仍固定 e7bc374；配置变更作为独立 0.66.0 预览，不把公开授权视为 TV 部署或设备验收。结果见[公开发布记录](../releases/2026-10-26-publication.md)。
