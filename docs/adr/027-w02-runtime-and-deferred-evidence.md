# ADR-027：W02采用已验证电视内路线，保留未通过项

日期：2026-10-17；状态：W02实施路线确定，完整产品/设备验收未完成。

依据：ADR-001的单App/无外部常驻服务约束；W01_EXIT_CHECKLIST的固定最小门槛；本电视已取得的签名/独立运行、Worker/WASM/Socket、现代TLS/cookie/保护存储、AVPlay/loopback/直播中转/1→2→1倍率与声画、官方三端基础投屏的分项证据。对应source/signed/UTC见IMPLEMENTATION_STATUS及TEST_REPORT，不将不同包/电话/人工与自动证据合并冒充一次完整验收。

用户已要求没有画质/权限的4K/HDR先跳过；1080及以上投屏入口实际提示仅官方设备可用。用户本轮又称账号没有开启历史记录，云进度这一项可以跳过。该设置是用户陈述，未独立检查，不能据此认定它就是两次回读0的根因。018实际20秒POST获API0、回读0仍保留为未确认；两次明确单次授权均已使用，两个意图不删除/改名/重发。UTC2026-10-17T19:41:10.936239+00:00精确匹配018最终account.local_session_deleted PASS，用户也确认已清除；只删除本探针KeyManager凭据，诊断GET后关闭true。

决定：收束本轮W01用户配合探针，标为**带用户跳过/条件不足项的阶段归档**，不标全项PASS。沿一WGT、TypeScript strict本地静态Web UI、实际DOM焦点、电视内Worker/WASM（已固定的Samsung Socket/cURL/OpenSSL依赖）、AVPlay与受限loopback媒体桥推进W02。esbuild为现有开发期构建器；电视运行不需要Node、开发电脑、NAS或项目云网关。模块只由composition root装配，探针身份/一次意图不进入正式业务会话设计。现有可验证依赖优先复用，不为换框架重写已验证的平台适配器。未出现证明必须改.NET的目标机阻塞，因此不额外开展.NET/第二播放器完整实验。

这项实施决定允许后续基础工作继续，不将被跳过的验证变为成功，也不删除F07/F19。云进度的真实有效性与双向接续仍记F07/W03未验证；高码率/4K/HDR及真实回退仍记F19/W04；完整发送端×内容/快速切P/故障恢复在W04/W06，耐久/跨功能在W07。正式发布前按届时的用户范围与实际能力复核；W01的用户跳过不自动豁免v1.0.0完整功能验收。

W02首批交付：可复用导航/模态与焦点返回合同；页面/媒体/账号任务的资源owner、异步关闭与未知关闭屏障；应用生命周期只在前台重校验后恢复交互，隐藏不自动恢复播放。使用本地合成/匿名行为测试及独立预览，不改已安装主060/独立018，不要求用户重复扫码、写入、关电脑或媒体检查。设备引擎major和性能数值仍未知，W02性能基线另记，不伪造测量。
