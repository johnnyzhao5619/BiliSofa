# ADR-066：按分P持久化的本机队列

2026-10-21，W03/F05/F07，内部候选0.27.0。本批完整交付普通视频队列与分P/当前身份媒体整合，不包含PGC队列、云端列表增删或云进度写回。F05类型/权限完整矩阵及W07真实自然结束/压力验收不因实现完成而通过。

## 数据与兼容

队列身份由BV扩展为BV＋part（1–10000），标题仍为有界安全文本，最多64项。相同P去重，不同P可分别排序、移除、播放。仅持久化公开BV、P号和标题，不保存CID、源URL、Cookie或私有列表游标。

新键`bilisofa.queue.v2.<固定身份>`使用schema2；旧`queue.v1`缺省为首P，仅当v2不存在时读取旧schema1。读取不写盘，第一次显式编辑才将当前队列写入v2并回读确认；旧v1字节保留供旧版本回退。当前v2损坏/未来格式不回退旧数据、不自动覆盖。旧版本仅看到自己的旧队列快照，不会把P2误作P1；跨版本双向同步不在该存储合同内。

清空/移除账号覆盖两个键：先删旧v1并确认，再删v2并确认，避免删除v2后旧数据复活。任何未确认均明确反馈，不影响其他身份、已有分P续播或未知账号写日志。新增分P队列是本地数据，无云端账号写权限变化。

## 入口与播放

普通播放页按当前实际P入队；云端历史有公开BV与有效P时保留该P，未提供P时明确按首P。稍后再看/收藏未提供具体P，仍标明首P。非UGC、缺BV、已失效/状态未确认条目继续禁用，不把显示列表当媒体权限。

队列读取不自动播放。显式播放使用当前固定身份的原生产VodAccess，按存储的P重新获取真实详情/源；P不再存在或权限失败时停止并保留失败项，不播放首P代替、不跳项。仅旧匿名首P播放器可用时P2禁用。续播读写对应身份的BV＋P；初始项可显式继续，手动/自然下一项从头，完成仅删除对应P记录。

固定快照、实际decoder/transport双关闭与epoch约束沿用ADR-048。Back/Home/换号取消当前工作，等待关闭期间不能产生下一个解码器；未知关闭保持阻断。方向卡片ID包含P，排序/删除后恢复到正确条目。

## 证据

schema/容量/迁移/回读、同BV双P、错误不跳项与取消、生产Worker/播放器合成界面及整包来源门禁分层记录。电视只集中验收该队列模块，不重复已通过推荐、投屏或叠加。旧0.26.1源码/包与推荐USER PASS保持冻结；当前候选和真机清单见实施状态。
