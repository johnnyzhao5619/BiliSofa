# ADR-051：完整F06交付与分P续播边界

状态：2026-10-20，0.21.1 A/B所请求控制、轨道、分P/记录与结束策略USER PASS；跨内容回退由[ADR-055](055-runtime-media-fallback.md)补充，0.21.3电视复核待完成。

用户要求完整F模块后统一验证，F06的出口由[F06_MODULE_DELIVERY](../F06_MODULE_DELIVERY.md)约束。不得按单控件/单入口反复部署和请求人工验收；旧0.20.0验收记录保留。用户随后将统一验收批次扩大为W04（F06、F17–F19），因此完整F06也不单独部署验收；不降低本ADR的实现门槛。

源端详情、私密CID、签名CDN地址和SegmentBase仅由媒体Worker解析持有。规范化清单向UI暴露当前媒体身份、质量/编码/音轨说明和有代次的选择标识，不暴露任意URL/CID或凭据。accept_quality/support_formats等广告清单不是权益证明，只有实际返回的非预览、非DRM DASH轨道可作为候选；运行时候选政策与实际播放结果分开，不由码流标签推断硬件通过。

切源必须先取得旧decoder与transport真实关闭。相同媒体切轨保留实际播放位置和暂停意图，新P/合集项从对应身份读取本地位置。准备完可保持逻辑暂停，继续之前不执行隐藏play/pause。倍速命令接受与有效声画速率为不同证据，当前只采用已有本机1/2倍观察范围，切源重置策略必须显示。

原`bilisofa.local.v1.<固定身份>`的首P/schema1不改写格式。新增`bilisofa.parts.v1.<固定身份>`，独立schema1、128条/32KiB，键为BV+part，仅保存P2及以后。首P继续读写原记录；完成某P仅删除该P位置，旧版回退不会把P2误作P1。损坏/未来数据不自动覆盖。当前身份本地重置或账号移除会尝试并核对两个分区删除，不操作其他身份和未知云写防重复日志。它是本地普通观看记录，不是登录凭据或云进度。

新生产媒体桥须与W01探针编译策略区分，不能将内部900秒/128MiB/512累计连接配额沿用为产品功能限制。请求/内存/并发、目标、TLS、取消及源过期处理仍须有界。在新生产桥接通并通过本地门槛前，不把已有探针改名为完整F06，也不改写已冻结源码/签名包证据。

生产装配采用两个由主线程创建的Worker，经转移MessagePort交换私密源，不依赖未验证的嵌套Worker或两个Emscripten运行时共享Module。关闭顺序为native桥关闭→源请求排空/释放确认→父线程关闭ACK；未知保持阻断。同轨续期仅替换签名地址，要求媒体身份、编码/索引/长度相同，且不重建解码器。详情/轨道公共DTO和固定枚举可回UI，凭据/CID/CDN地址不可回UI。
