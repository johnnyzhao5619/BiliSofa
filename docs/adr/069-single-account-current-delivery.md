# ADR-069：当前版本跳过真实双账号功能与验收

**状态：已由[ADR-120](120-next-phase-scope.md)取代（2026-10-27）。多账号登录重新纳入交付范围；下文保留的隔离与代次机制仍是实现基础。**

2026-10-21，依据用户指示：“当前版本不需要真实双账号功能，该功能可在当前版本跳过”。本条覆盖原PRD、W03/W07出口和交付提示中的真实双账号要求。

## 当前范围

当前版本以单账号使用为交付目标；真实双账号功能扩展、A/B切换与私人内容对照验收不作为发布门槛，不再索要第二账号或安排相关测试。F13保留编号，标记当前版本用户排除（EXCLUDED），不是已验收PASS，不承诺后续版本或日期。

已实现的多账号保存/选择/移除、普通KV分区、账号代次及历史证据全部保留，不删除已有账号或迁移用户数据。此决定不要求当前运行时强制只能保存一个账号，也不表示原多账号实现已通过完整验收。

单账号登录、身份核对、退出/删除、会话失效与重新登录、保护会话、游客与账号数据分离、凭据限定和旧请求取消仍是F01/F12及安全要求；共享的隔离/代次机制不能因跳过双账号而拆除。已有合成隔离检查可保留，无需为本范围调整新增或重复应用测试。

本条仅改变真实双账号范围，不改变F11可逆互动、具体账号写入授权或F20不同官方发送端/争用边界。直播继续按ADR-068排除当前交付；其他实现与验收缺口保持原状态。

## 执行

更新需求、实施状态/计划、进度复核、验收与发布清单及交付提示；从当前待办删除真实双账号门槛。无需重打包、部署或触碰会话/源码工件；现有0.28.0与验收记录保持。后续继续续播名称、直播入口隐藏和F11可逆互动，不以第二账号缺失阻塞它们。
