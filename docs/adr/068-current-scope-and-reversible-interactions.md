# ADR-068：最新范围与可逆互动恢复实施

2026-10-21，依据用户在0.28.0验收后的指示：续播应显示视频名称；“直播不做”；4K播放测试成功；增加关注UP、收藏视频、加入稍后再看并复核进度。

## 范围覆盖

- 当前交付不再包含直播功能，也不以直播实播/画质/消息/投屏验收阻塞收口。F18及F16/F20直播依赖分支保留编号/代码/历史失败，标记用户排除，非PASS；不承诺后续直播版本。覆盖ADR-057原“仅实播延期、保留当前浏览交付”的范围表述。现包直播入口尚未隐藏，下一候选须统一隐藏首页/搜索等入口，不能称当前已移除。
- 用户报告4K播放成功，记录为USER声画通过。未提供本轮源/decoder尺寸、编码、fps、HDR或新型号证据，不外推3840×2160、HDR和跨设备矩阵；不重复基本起播验收。
- 恢复F11关注/取消UP、收藏夹增删、稍后再看增删及点赞相关实现/只读排查，覆盖ADR-063对这些可逆操作的暂停。原POST实现/持久日志保留，不能从“增加功能”推断具体真实账号测试目标/次数。
- F14投币/三连、F17真实追番与云进度原边界不变；投币和三连不能因恢复F11被无条件开放。真实写测试先具体验证目标/收藏夹/方向，单次授权、提交后回读，unknown不自动重发。

## 当前可确认缺陷

本机位置格式没有标题，0.28.0按BV/P展示是实现事实，与用户期望不符。后续优先复用播放/列表已经取得的名称，持久化有界的独立身份标题元数据；旧记录可有界补取本页名称，不应为显示标题获取播放源或批量扫描全部记录。失败明确后备，保留BV作为次要识别。删除/清空/账号移除须覆盖相应元数据，保护旧记录/回退格式。

F11已有原生固定GET/POST、预览、单次grant、持久journal与回读实现；产品播放页却按W06标志无条件禁用全部互动。只移除禁用不足以恢复：旧状态读取还串行依赖余额/投币、收藏夹、关系和稍后再看等，任一字段解析失败会让全部操作不可用；历史`interaction.invalid`没有子阶段证据，不能唯一归因。恢复时先细分只读阶段与安全结构分类，拆开可逆操作和投币前置条件，再接通F11入口及取消/提交/回查组合。不使用重复盲测代替定位。

本ADR不记这些待实现变更已交付。当前冻结0.28.0所请求A–D USER PASS，名称体验缺口OPEN；实施/最终门槛见进度复核。
