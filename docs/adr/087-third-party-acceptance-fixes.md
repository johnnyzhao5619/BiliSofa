# ADR-087：第三方验收问题的源码修正

2026-10-22；F10/F11/F15/F19、R03/R07/R10/R15。依据[第三方独立验收](../acceptance/third-party/2026-10-22T213335-0400/REPORT.md)及用户随后“按建议实施”的授权。状态：**源码修正、本地检查通过；随后经用户授权构建并签名0.44.0候选（[工件证据](../design/evidence/2026-10-22-acceptance-fix/README.md)），并经授权升级安装到电视（平台确认，不清数据）；用户所请求M1回复全文/M2默认画质USER PASS**（[用户结果](../design/evidence/2026-10-22-acceptance-fix/USER_ACCEPTANCE.md)）。

## 决定

- **P1-02 F11互动日志终身上限**：`InteractionWrites`在日志满256条时，按时间先后淘汰已结算的可逆行（confirmed/not-applied/not-sent）及从未发送的投币行，再写入新意图。pending/unknown以及已确认或未知的投币行一律不淘汰；如果全部为这类行，仍在POST前拒绝（`invalid`）。这样不改变防重放、单次POST和回读合同，旧日志格式和上限不变。`retained-writes`（追番/进度）的“同目标已确认即阻断”有语义作用，本次不淘汰，保留为P3-01。
- **P2-01 评论回复全文/层级**：回复卡片的全文详情改用独立弹窗ID `comment-reply-detail`。导航不同模态的上限由4层改为6层（`MODAL_LIMIT`），覆盖最深的产品路径“收藏夹 → 播放器 → 评论 → 根评论全文 → 楼中楼 → 回复全文”；番剧/收藏夹播放下的叠加过滤词输入也随之可达。Back仍然一次只消费一层，同一ID仍拒绝重复打开。
- **P1-01 R07倍速观测**：判定从“期望值±25%”改为：实际斜率必须严格更接近期望档位，而不是更接近停顿(0)或任何其他产品档位，并且偏差不超过期望值的20%。8×8档位组合加停顿只有对角线匹配，setter接受但实际仍为1×不能通过1.25×。这只是收紧判定；时间更新粒度较粗时，结果可能为mismatch并保持UNVERIFIED，不会误记PASS。既有桌面0.25/0.5/0.75/1×比例为25/50/75/100，在新判定下仍匹配；1.25×及以上的旧观测不能沿用。
- **P2-02 首播默认画质**：无已记偏好时仍然AVC优先（ADR-055），随后选择不超过1080P（qn 80）的最高档，同档取较高码率。只有不存在≤80档时，才取其上最低档。1080P+、4K、HDR和杜比视界不作为默认，用户显式选择后在本身份内存偏好中沿用。音频默认原本已是最高AAC，不变。失败降级（只降不升、最多4次）不变。
