安装指南 / 安卓手机

用安卓手机安装

拿起手机和遥控器，跟着四步操作。无需自己编译。

开始之前适用于声明支持 Tizen 9.0 的三星电视。0.66.0 是预览版，尚未完成电视安装和运行验收；安装需要开发者模式和有效的 Samsung TV 证书。
01

先下载两个文件

在安卓手机上操作。APK 是手机安装工具，WGT 是电视应用包，请不要解压 WGT。

① 安装工具Apps2Samsung · 安卓 APK下载 APK ↓② 电视应用BiliSofa 0.66.0 · WGT下载 WGT ↓

打开下载好的 APK，按照手机提示安装 Apps2Samsung。WGT 保存在「下载」文件夹即可。

手机提示不允许安装？

确认 APK 来自 Apps2Samsung 官方 GitHub，按手机提示允许当前浏览器或文件管理器安装；完成后可关闭此来源的安装权限。

Apps2Samsung 是独立第三方工具，按钮指向其官方 GitHub 的 2.8.3 版本。本项目不维护该工具；此安装路径尚未使用 BiliSofa 独立实测。了解工具 ↗

02

打开电视的开发者模式

先在手机的 Wi-Fi 详情中找到并记下它的 IPv4 地址。手机或电脑与电视需连接同一网络。

  1. 电视按 主页 → Apps → App Settings，输入 12345。
  2. 将 Developer Mode 设为 On，填入手机的 IPv4，确认。
  3. 根据提示重启电视。
在哪里找 IPv4？

安卓：设置 → Wi-Fi → 已连接网络 → 详情。Windows：按 Win + R，输入 cmd，在窗口输入 ipconfig，查看当前网络的 IPv4。Mac：系统设置 → 网络 → Wi-Fi → 详细信息 → TCP/IP。菜单名称可能因系统版本不同。

03

在手机上选择电视并安装

  1. 打开手机上的 Apps2Samsung，选择你的电视；找不到时可按工具提示手动填写电视的 IP。
  2. 在应用选择栏选择 Custom WGT / TPK…，从「下载」中选中 BiliSofa-0.66.0-unsigned.wgt。
  3. 选择安装，按提示使用自己的 Samsung 开发者账号和电视证书完成签名、安装。

保留自己的 Author 证书，以便后续更新。无需将证书或账号交给项目维护者。

电视 IP 在哪里？

一般在电视的网络设置或网络状态中。它与第 2 步填写的手机 IP 是两个不同的地址。

回到电视，开始使用

在电视 Apps 中打开 BiliSofa，首次输入 www.bilibili.com 并确认。可以先以游客身份浏览，或按提示使用官方 Bilibili App 扫码登录。

遇到问题？

先查看下方常见问题，也可以在 GitHub 提交电视型号、固件版本和脱敏后的错误信息。

找不到电视或连接失败

确认电视和安装设备在同一可信局域网，开发者模式已开启且电视已重启。电视里填写的是安装设备的 IP；工具手动查找时填写的是电视 IP。检查路由器是否隔离设备。

提示证书或安装失败

按工具提示检查自己的 Samsung 开发者账号和目标电视证书。更新时先找回原 Author 证书；不要把卸载或清除数据作为默认修复。

安装后打不开、无法播放

0.66.0 尚未完成电视运行验收。请确认电视系统、网络和内容权益，并反馈型号、固件与脱敏错误。
