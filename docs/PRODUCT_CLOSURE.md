## 集中验收清单

T1–T8为最终组合验收矩阵；当前没有待执行的设备测试组，见[当前验收](CURRENT_DEVICE_TEST.md)。

| 组 | 最终组合路径 | 通过依据 |
| --- | --- | --- |
| T1 浏览/导航 | 启动→首页内容→榜单/分区→详情→原卡；刷新与追加时内容不跳动；网络慢/失败不失焦 | 真实内容、远距可读、方向/返回；来源阻塞按R04/R05保留 |
| T2 搜索/UP/动态 | 首字母选词→综合/视频/UP/番剧→详情/播放→原结果；热搜/历史开关 | 无首列死区/误搜索；返回保词、筛选和原卡 |
| T3 账号/我的 | 两个账号分别登录→私人片库→队列/续播→切换账号→设置；过期重登录恢复原目的 | 身份与数据一致、互不串用；退出后私人页释放 |
| T4 播放/阅读 | UGC与PGC→暂停/非零seek/选P集/轨道回退/全部倍速档→字幕弹幕/评论→原卡；自然结束队列一次 | 声画/进度、叠加同步、控制层隐藏/唤回、返回锚点 |
| T5 互动 | 只补受影响的身份/未知写故障；F14按暂停决定 | 用户确认实际账号状态；unknown只查询不自动重发 |
| T6 投屏 | 三端受影响路径；代表发送端完成控制/换P/争用/停止；Home后重新允许接收 | 原官方App，声画/双端时间与所有权一致 |
| T7 可用性 | 远距中文、长标题、深列表、设置页、减少动画、弱网/空态/权限提示 | TV实测焦点与远距可读；Voice Guide按ADR-089非需求 |
