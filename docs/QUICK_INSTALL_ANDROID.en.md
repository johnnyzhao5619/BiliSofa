# Install BiliSofa 0.66.0 using an Android phone

[中文详细教程](QUICK_INSTALL_ANDROID.md) · [Computer installation](QUICK_INSTALL.en.md)

This route can be attempted without a computer or compilation. Apps2Samsung is an independent third-party tool; its v2.8.3 Android source includes local WGT selection, TV connection, certificate provisioning and installation. **Neither this route nor BiliSofa 0.66.0 has completed independent TV acceptance.** Results depend on your phone, network, TV and certificate.

1. **Get ready.** Use a Samsung TV that meets the package's Tizen 9.0 requirement, its remote, and an Android phone connected to the same trusted Wi-Fi / LAN. A Samsung developer account may be needed when generating a TV signing certificate.
2. **Download two files on your phone.** Save the [BiliSofa unsigned WGT](https://github.com/johnnyzhao5619/BiliSofa/releases/download/v0.66.0/BiliSofa-0.66.0-unsigned.wgt) in Downloads; do not extract it. Download and install the [Apps2Samsung Android APK](https://github.com/Apps2Samsung/Apps2Samsung/releases/download/v2.8.3/Apps2Samsung-v2.8.3-android.apk) on the **phone**. If Android asks for permission to install this APK from your browser or file manager, verify it came from the upstream GitHub source, follow the system prompt, and optionally turn off that source's permission afterward. The APK is the installer; the WGT is the TV app.
3. **Find the phone's Wi-Fi IPv4 address.** Open Android **Settings → Wi-Fi → connected network → details / advanced**. Menus vary by phone. Note the phone IPv4 address on the TV's network; do not post it publicly.
4. **Enable TV Developer Mode.** On the TV go to **Home → Apps → App Settings**, enter `12345` on the remote or on-screen keypad, set Developer Mode **On**, and enter the **phone's IPv4 address**. Confirm and restart the TV. Apps should then show Develop Mode. See [Samsung's TV guide](https://developer.samsung.com/smarttv/develop/getting-started/using-sdk/tv-device.html).
5. **Install from the phone.** Open Apps2Samsung and select your switched-on TV; if needed enter the TV's own network IP, which differs from the phone IP. In the app selector choose **Custom WGT / TPK…**, select `BiliSofa-0.66.0-unsigned.wgt` in Downloads, then tap **Download and Install / Install**. Follow any Samsung account and certificate prompts. Signing is required for TV installation; keep the Author certificate for updates. Do not share credentials, keys, certificates or DUIDs.
6. **Open BiliSofa on the TV.** On first use, enter the website you want to watch, for example `www.bilibili.com` or `bilibili.com`, and confirm. Only Bilibili is currently supported. Start as a guest or use your own official Bilibili app to scan the sign-in code. The TV needs Internet for viewing; the phone need not stay running afterward.

If the TV is missing, check both devices share a network, Developer Mode is enabled, the TV restarted, and the correct phone / TV addresses are used. Check router isolation. If signing fails during an update, recover the original Author certificate before considering uninstalling or losing data. For a missing file, check Downloads and choose the WGT, not the APK. For a failure or startup issue, report only redacted details and TV / firmware versions in [Issues](https://github.com/johnnyzhao5619/BiliSofa/issues); you can also try the [computer route](QUICK_INSTALL.en.md).
