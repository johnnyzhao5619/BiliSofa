02

打开电视的开发者模式

先在电脑的 Wi-Fi 详情中找到并记下它的 IPv4 地址。手机或电脑与电视需连接同一网络。

  1. 电视按 主页 → Apps → App Settings，输入 12345。
  2. 将 Developer Mode 设为 On，填入电脑的 IPv4，确认。
  3. 根据提示重启电视。
在哪里找 IPv4？

安卓：设置 → Wi-Fi → 已连接网络 → 详情。Windows：按 Win + R，输入 cmd，在窗口输入 ipconfig，查看当前网络的 IPv4。Mac：系统设置 → 网络 → Wi-Fi → 详细信息 → TCP/IP。菜单名称可能因系统版本不同。

03

连接电视并创建证书

在 Tizen Studio 的 Device Manager 中连接电视，然后在 Certificate Manager 选择 Samsung → TV，使用自己的 Samsung 开发者账号创建证书，并按提示添加目标电视。

保留 Author 证书供以后更新；证书和密码保存在自己的设备中。

遇到问题？

先查看下方常见问题，也可以在 GitHub 提交电视型号、固件版本和脱敏后的错误信息。

找不到电视或连接失败

确认电视和安装设备在同一可信局域网，开发者模式已开启且电视已重启。电视里填写的是安装设备的 IP；工具手动查找时填写的是电视 IP。检查路由器是否隔离设备。

提示证书或安装失败

按工具提示检查自己的 Samsung 开发者账号和目标电视证书。更新时先找回原 Author 证书；不要把卸载或清除数据作为默认修复。

安装后打不开、无法播放

0.66.0 尚未完成电视运行验收。请确认电视系统、网络和内容权益，并反馈型号、固件与脱敏错误。
