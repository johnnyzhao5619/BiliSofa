# 门户维护

门户由 [GitHub Pages](https://johnnyzhao5619.github.io/BiliSofa/) 提供，发布来源为本仓库 `main` 分支的 `docs/`。`docs/.nojekyll` 使静态资源按原样发布。

- 首页为 `docs/index.html`；安装详情页与样式位于 `docs/portal/`。
- README 和首页中的安装入口应与实际页面路径一致；移动页面前应检查旧链接和外部引用。
- 提交并推送后，等待 GitHub Pages 完成构建，并核对主页、安装页、样式与下载链接。
- 产品界面图片使用合成数据，不能作为当前发行包的实机验收证据。

门户只介绍当前公开预览版；图形安装路径、电视安装与运行仍需实际验证。此前发布过程可在[固定历史提交](https://github.com/johnnyzhao5619/BiliSofa/blob/940d96985671da169406fb88e1f9818291681aca/docs/portal/DEPLOYMENT.md)查阅。
