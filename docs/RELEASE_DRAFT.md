## 0.65.1 正式开源基线

BiliSofa 起于一个实际不便：海外 Samsung Tizen 电视上没有可用的 Bilibili 应用。这个独立客户端让浏览、搜索、观看和遥控操作在电视上完成，日常无需常开电脑、NAS、网关或项目云端。

软件精确固定 `e7bc3740e0fed2f9b2c89f9a83755398fa11faf7`。使用本 Release 未签名 WGT，无需自己编译；在电脑上用自己的 Samsung TV 证书签名，通过 Developer Mode 安装。参阅[五步安装](QUICK_INSTALL.md)，选择本版文件，跳过首次填写网站步骤。该第三方工具路径未独立实测；官方工具备选见[完整指南](INSTALLATION.md)。最低声明 Tizen 9.0；已有分项证据型号 Samsung UN58U8200FFXZC，其他电视未证明兼容。

推荐 / 热门 / 分区、搜索、点播 / 番剧、分 P / 选集、队列 / 本地续播、1× / 2×、字幕 / 弹幕 / 评论阅读、扫码账号 / 私人片库与保留互动、前台开启后的官方 App 投屏接收均按既有范围提供。图文 / 关注动态来源阻塞，投币 / 三连暂停，双向云进度及 iPad / 全内容投屏等未完成验收。直播和真实双账号不在当前交付范围，讨论只读。详见[版本与证据](releases/0.65.1.md)。公开不等于完整 v1.0.0 或全型号通过。

## 0.66.0 服务配置预览版

在上述基线上加入“先填写网站，再启用 WGT 内对应地址配置”。首次输入 `www.bilibili.com` 或 `bilibili.com`；当前只支持此服务，不是任意网站浏览器，没有外部后端 / 远程脚本。设置可重新填写地址并退出，保留账号、观看记录与未知写入记录。

下载本版 WGT 或完整 download ZIP，按[五步安装](QUICK_INSTALL.md)侧载。**预览版已重新编译原生模块 / Web 并通过静态打包检查，尚未完成电视运行、安装或升级验收**；没有运行应用测试，不沿用旧版的设备通过。独立源码提交和摘要在本版 manifest，不能填写成 e7bc374。最低 Tizen 9.0、应用身份 `BiliSofa01.TV`，更新保留原 Author。详见[预览说明](releases/0.66.0-service-configuration.md)。
