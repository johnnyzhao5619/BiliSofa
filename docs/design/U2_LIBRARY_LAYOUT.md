# U2 继续观看与我的片库布局

2026-10-21，实施基准，未真机验收。沿用U1的夜蓝/面板蓝/白字/蓝灰次文与粉色焦点，48px页标题、30px卡片标题、26px进度，系统中文黑体；不新增装饰性海报或字体。

首页在已有记录时显示一行四张紧凑“继续观看 · 本机”卡：标题、P号/名称、已看/总时长、进度条；无记录不占空货架。热门/推荐仍独立加载，断网不影响本机继续观看。

“我的”使用同页分类＋四列内容：继续观看、本机播放队列、稍后再看、云端历史、收藏夹。每个分类记忆页码/焦点；收藏内容在独立子层返回原夹。卡片详情统一标题/来源/权限/进度与明确动作；队列保留上移/下移/移除、连播开关及从此项播放。云端条目只读，只有有效普通视频且分P已知才开放播放/本机入队，不把未知类型当首P。

公开封面仅沿用受限图片适配器；源未提供时使用文字/类型后备，不虚构时长、UP或封面。本机记录不为补名发网络请求。第一列左到当前导航，上到分类，下到分页；侧栏右回原区域。删除默认保留，执行后按稳定ID或最近邻恢复，缺图/迟到响应不抢焦点。

首页默认进入已有本机卡，否则进入首个可用视频。播放前关闭详情；Back返回原卡，Home立即释放媒体。账号改变清除旧片库视图/请求与内存浏览锚点，不清除保存的数据。旧测试面板和旧工件保留；播放器/账号设置外观仍交U3–U4。
