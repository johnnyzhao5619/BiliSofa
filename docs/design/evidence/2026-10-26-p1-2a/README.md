# ADR-113 设备实按：P1-2a卡片直接播放、长按菜单、续播与快捷设置条（0.60.0）

2026-10-26。用户授权签名、安装0.60.0，并在电视上按ADR-113的按键数表逐项实按。

- **设备**：Samsung UN58U8200FFXZC，Tizen 9.0，原装遥控器，登录状态。
- **包**：0.60.0未签名`28a4b6a7…b460`，签名`d1b70a6f…8af`（证书预检PASS，权限不变）。升级安装、启动均platformSuccess（一次，不清数据）。

## 方法

- 调试启动后，用[ux.mjs](ux.mjs)经Inspector在页面里记录两类数据：
  - 按键名（`keydown`，以及OK的`keyup`）；
  - 每100 ms一次的界面状态：焦点控件、菜单、详情页、播放器、快捷设置条、“从头播放”、提示、AVPlay状态、状态行前40字。
- 记录不阻止按键，应用照常响应。焦点id里的视频编号与账号编号都已替换为`BV*`、`bili_*`，不记录标题。
- 用户按给定步骤实按，并确认各步都与描述一致。原始记录：[ux-0.60.0.json](ux-0.60.0.json)。

## 发现的问题（未修）

1. **换画质后快捷设置条不收起。**
   - 快捷设置条打开时控制层保持显示，所以选完画质后，退出播放器要按三次返回：收起快捷设置条→收起控制层→退出。
   - 建议：在条上选完一项（打开的选择器关闭后）就收起快捷设置条，或在控制层空闲时一并收起。
2. **首帧前按“从头播放”会整条重读。**
   - 第③步在“缓冲中”时按了“从头播放”，按设计走“重新开始这一项”，从按下到首帧7.4 s；首帧之后按则只是一次跳转。
   - 建议：首帧前改为“取消续播位置、从0准备”，不重新读取；或者首帧前不显示这个按钮。
