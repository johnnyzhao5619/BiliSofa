# U1 首页视觉实施基准

2026-10-21；依据 TV_PRODUCT_DESIGN，不是电视截图或已验收界面。

主任务：坐在沙发上选视频、看详情、播放并回到原卡。首页用实际内容，不加虚构推荐或装饰性大海报。1080p逻辑画布，安全边距64px，左侧96px导航，内容从224px起，四列封面卡。导航聚焦时展开文字，覆盖内容而不重排卡片。

色板：夜蓝 `#0c1524`、面板蓝 `#16263b`、卡片蓝 `#20354d`、正文白 `#f4f7fb`、次文蓝灰 `#a9bad0`、B站语义粉 `#fb7299`。粉色只用于可见焦点和播放主动作；当前导航另用左侧标记，选中与聚焦分开。标题用本机中文黑体粗体48px，卡片标题30px，UP/时长26px，工具28px；不下载字体。

识别点：B字标与侧栏当前目的地的短粉色标记；其余空间让给封面和中文标题。缺图呈现统一品牌底与标题，不生成假封面。长标题详情全文可读；来源、页码、空/错/更新中的旧内容明确。布局适配是逻辑画布缩放，不能据桌面截图声明电视可读性、Voice Guide或焦点时延达标。

本轮范围：主壳层、首页/视频搜索卡片、UGC首P详情及原播放器接入。其余目的地保留可用模块入口与既有面板；统一搜索类型、继续观看货架、私人列表/播放器视觉迁移仍属U2–U4。
