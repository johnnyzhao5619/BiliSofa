# U2 统一搜索布局

2026-10-21，源码实施基准，电视验收待整包。沿用 U1 夜蓝、白字、粉色焦点、48px 标题及四列卡片；不新增字体、装饰图片或外部服务。

```
搜索                          视频、UP主、番剧影视
[输入关键词：你好] [热搜] [搜索历史]
[视频] [UP主] [番剧影视]
“你好” · 视频 · 第 n 页 / 加载 / 空 / 错误
[封面+标题] [封面+标题] [封面+标题] [封面+标题]
[上一页] [下一页] [刷新]
```

一次输入后切类型复用同一关键词，各类型记住页码；新关键词全部回第一页。热搜/历史仅选择关键词，之后回同一结果页。第一列左到搜索导航，卡片上到当前类型、下到分页；侧栏右回内容锚点。每个详情 Back 回原卡，播放前关闭详情，避免遮挡 AVPlay。

视频卡保留继续/从头和本机入队；UP卡只展示源提供的统计与附带视频预览，不声称完整UP主页；番剧卡使用真实搜索摘要，进入已有季/集工作区。缺封面用类型文字，不伪造来源事实。源错误展示经过验证的末尾码并提供手动刷新，不自动无限重试。

切类型/关键词取消旧请求并等待原生关闭确认；迟到响应不覆盖新结果或抢走导航/弹窗焦点，关闭未确认则阻止继续复用。Home释放搜索资源。旧构建、旧面板及账号写入边界保持；直播不列入搜索类型。
