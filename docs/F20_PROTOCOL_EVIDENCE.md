# F20 官方投屏证据

更新：2026-10-19。目标是未修改的官方Android/iPhone/iPad App直接发现并控制电视中的BiliSofa；不是Smart View、屏幕镜像或复制链接兼容，也不宣称官方认证。

## 当前实现边界

- 用户在电视前台明确允许接收，Worker处理SSDP、服务描述与有界SOAP控制；源经目标/格式/TLS检查后交电视内部媒体桥。
- `CastSession`/`ReceiverLink`/`CastWorkspace`管理源代次、发送端/遥控控制权、真实时间和双关闭；签名CDN地址不进UI/普通存储或日志。
- 一个活动解码器；Home/结束会话撤销接收权限、停声并清理。没有承诺后台接收、冷启动、唤醒或AirPlay支持。
- 探针租期/累计预算仍需产品化；支持一个样本不等于所有码流/完整F20。

## 已确认的开发经验

- 首次SetAVTransportURI握手需与电视事先允许的会话一致；早期拒绝后才人工起播会造成发送端未登记媒体，界面长期0:00–0:00。有限元数据/发送取证本身没有解决该问题。
- SOAP服务描述、实际发送完成、时间回传与手机UI分别取证；字幕/画质/认证不能由协议标签猜测。
- 暂停态定位可能重建解码器并停在预缓冲IDLE；保持逻辑暂停直到用户继续，不用隐藏play/pause制造成功。
- 大moov索引按已知大小设置准备活动窗口，仍限制无进展/绝对等待；忙碌时不读不允许的AVPlay状态。
- CDN范围、TLS、原生清理失败分别分类；单次短P通过不能替代连续稳定性。
- iPad先核对正确App和本地网络权限；不通过冒用官方设备身份解除画质限制。
