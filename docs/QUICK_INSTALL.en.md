# Install BiliSofa 0.66.0 on your Samsung TV

[简体中文详细教程](QUICK_INSTALL.md) · [Android phone route](QUICK_INSTALL_ANDROID.en.md)

No compilation is needed. You need a Windows or Mac computer, a Samsung Tizen TV on the same network, and a Samsung account if a new TV signing certificate is required. The package requires Tizen 9.0. **Version 0.66.0 has not completed TV installation or runtime acceptance; the third-party installation route has not been independently tested with BiliSofa.**

1. **Download both files.** Download the [0.66.0 unsigned WGT](https://github.com/johnnyzhao5619/BiliSofa/releases/download/v0.66.0/BiliSofa-0.66.0-unsigned.wgt) and Apps2Samsung for [Windows](https://github.com/Apps2Samsung/Apps2Samsung/releases/download/v2.8.3/Apps2Samsung-v2.8.3-win-x64.msi), [Mac Apple silicon](https://github.com/Apps2Samsung/Apps2Samsung/releases/download/v2.8.3/Apps2Samsung-v2.8.3-macos-arm64.dmg), [Mac Intel](https://github.com/Apps2Samsung/Apps2Samsung/releases/download/v2.8.3/Apps2Samsung-v2.8.3-macos-x64.dmg), or [Linux](https://github.com/Apps2Samsung/Apps2Samsung/releases/tag/v2.8.3). Save the WGT to Downloads; do not extract it. Install and open Apps2Samsung.
2. **Find your computer's IPv4 address.** On Windows, press `Win + R`, enter `cmd`, run `ipconfig`, and find the IPv4 address under the network you are using. On Mac, open **System Settings → Network → Wi-Fi → Details → TCP/IP** and find IPv4 Address (or select Ethernet if wired). Keep it private.
3. **Enable TV Developer Mode.** On the TV open **Home → Apps → App Settings**; enter `12345` using the remote or on-screen keypad. Set Developer Mode to **On**, enter the computer IPv4 address, confirm, and restart the TV. After restarting, Apps should show Develop Mode. Menus vary; follow [Samsung's illustrated guide](https://developer.samsung.com/smarttv/develop/getting-started/using-sdk/tv-device.html).
4. **Install.** With the TV switched on and both devices on the same network, open Apps2Samsung and select your TV. If discovery fails, use the TV's network settings to find its own IP and enter it in the installer if prompted. Select **Custom WGT / Custom WGT File**, choose `BiliSofa-0.66.0-unsigned.wgt` from Downloads, and click **Install**. Follow any Samsung sign-in and certificate prompts. The installer handles signing locally; Samsung requires a valid signature. Keep the Author certificate for updates and never share passwords, cookies, certificates or DUIDs.
5. **Open the app.** Find BiliSofa in TV Apps. On first launch enter **`www.bilibili.com`** or `bilibili.com`, confirm, and start as a guest. Optionally sign in using your own official Bilibili app. Your computer can be turned off after installation.

If the TV is not found, verify the network, computer IP in Developer Mode, TV restart and router isolation. For certificate conflicts, recover the existing Author certificate before considering uninstalling and losing local data. For a missing file, look in Downloads without extracting it. Report redacted errors and your TV / firmware in [Issues](https://github.com/johnnyzhao5619/BiliSofa/issues), never private credentials or device identifiers.
