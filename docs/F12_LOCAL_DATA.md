# F12本机记录与列表缓存管理

更新：2026-10-21。内部候选 **0.28.0 / BiliSofa W03**，已签名安装启动且所请求A–D USER PASS；续播名称仅BV待修。包和设备结果以[当前验收](CURRENT_DEVICE_TEST.md)为准。[ADR-067](adr/067-local-bookmarks-and-read-cache.md)规定清理范围与未确认恢复。

| 入口 | 当前行为 |
| --- | --- |
| 设置统计 | 合并当前身份首P与P2+记录，最多192项；有一分区不可读时不显示假完整统计 |
| 本机观看记录 | 按时间排序、四卡分页、详情/Back；仅显示BV/P和本地时间，不发请求或播放 |
| 删除/清空续播 | 独立确认；可仅删一个P，保留同BV其他P；清空续播保留偏好/队列/搜索/登录/未知写日志 |
| 失败恢复 | 损坏/未来格式不覆盖，跨键部分失败明确未确认，可重新读取；原明确重置入口保留 |
| 当前账号列表缓存 | 确认后关闭/取消旧读，清理内存推荐、历史、收藏夹、关注更新；保留登录及本机数据，下次重新读取 |
| 所有权 | 切账号/Home/Back不允许旧按钮删除或旧回包复活；关闭未知阻止成功与能力复用 |

## 一次集中验收

A. 进入“设置与本地记录→本机观看记录 · 含分P”，核对首P/P2位置与实际已看内容相符，检查分页（如有）、详情与Back回原卡。为空直接说明，不为此长播。

B. 对一条你愿意删除的测试视频P2记录，先取消删除，应保留；再确认“仅删除此分P位置”，应只删除该P，其他记录/队列/跳转步长不变。找不到可删测试记录可标未测，不删除需要保留的记录。

C. “仅清空本机续播位置”先看预览再取消，记录与偏好应保持。无需为测试确认清空全部已有记录；如自愿执行，可另报清空及偏好保留结果。最后正常退出重开，核对上述实际结果保留。

D. 使用已保存账号，先打开一次“当前账号推荐”再Back，在设置选“清理当前账号的列表缓存”：先取消，再进入确认清理。确认后仍应是本人账号，队列/设置保持，再打开推荐一次应能读取；失败即停并报页面固定错误，不连续刷新。游客下该按钮禁用为预期。

只反馈A/B/C/D实际结果，不提供私人BV/标题、身份或凭据。没有可选分页或删除样本直接标未测；不扫码、不写云进度/互动，不重测队列播放、投屏、叠加、评论或延期直播。完整类型/故障/性能仍OPEN。

验收回执：用户确认所请求组全部通过，并反馈续播内容应显示视频名称。当前本地格式没有标题字段，本页不将BV显示当作最终体验完成；后续须有界保存/补取名称，失败保留可辨识后备。
