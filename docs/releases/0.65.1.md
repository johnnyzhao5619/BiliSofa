## 已知限制

- **来源阻塞**：图文 / 关注动态；部分请求可能受 HTTP 412 / API -352 等拒绝影响。不以假数据或其他列表冒充目标来源。
- **暂停**：F14 投币 / 三连；实现和旧意图保留，未取得真实通过，不承诺可用。
- **云进度**：本地续播保留；双向云接续本轮被用户跳过，旧结果未知的写入不重发，不能称已完成。
- **倍速与媒体**：已测设备生产保持 1× / 2×；小数倍速按设备限制关闭。基本标称 4K 声画的用户结果不能外推为全编码、HDR、独立 decoder 参数或全型号支持。HDR 当前无需求；超过 24 小时视频待设备证据。
- **投屏 / 生命周期**：iPad、双发送端争用、部分定位精度、全部内容组合仍未验证；不承诺后台接收 / 唤醒 / 自动启动。
- **耐久与数据**：完整 30 条普通视频、两小时混合量化、跨任意版本回退 / 数据迁移与自然服务端过期等条件仍不完整；没有通用无损迁移保证。
- **范围排除**：直播及依赖分支、真实双账号；保留 F18 / F13 编号和历史。评论 / 回复 / 弹幕仅阅读，没有发送 / 编辑功能。

所有播放和账号能力均受真实权益、地区、内容来源与设备能力限制。版本号和 UI 选项不构成平台 / 内容授权或实机能力证明。
