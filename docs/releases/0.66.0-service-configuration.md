# 0.66.0 服务配置预览版

日期：2026-10-26。当前为未签名、未部署、未完成电视运行时验收的公开预览版。用户后续要求仅公开本版下载；原 0.65.1 Release 已转为草稿，历史包与 tag 保留。

## 新行为

首次使用时，用户自行填写想观看的网站地址，例如 `www.bilibili.com` 或 `bilibili.com`，并确认启用。目前仅支持 Bilibili；后续启动可复用已保存的选择，具体观看内容由用户自行选择。输入用于匹配随包提供的服务配置；相关 API / CDN 地址和平台适配由开发者提供，应用还包含浏览、登录和保留的账号互动功能，不是仅接收任意媒体地址的通用本地播放器。

已保存的选择在下次启动重新校验。设置 → 本机数据 → 重新填写网站地址可以清除选择并退出，保留账号、本机记录和未确认互动记录。配置缺失、网址错误或不支持时保持可恢复的设置界面；不会自动回到代码内的默认服务。

## 配置位置

- 服务目录：`apps/tv/service-providers/catalog.json`。
- 后端配置：`apps/tv/service-providers/bilibili-web.json`，其中 `addresses` 是具名域名表，`strings` 是请求 / 校验模板，`nativeKeys` 是稳定原生槽位顺序，`platformOrigins` 用来生成平台声明。
- Worker 在配置引导后才执行原业务代码，WASM 在 `main()` / Cookie 导入前完成一次性配置；缺失或不匹配的 schema 拒绝启动业务。
- Tizen CSP / WARP 中的域名仍必须随包声明。运行代码不直接写出业务域名，不代表 JSON 或发行文件里没有域名，也不表示取得平台授权。

完整合同和边界见 [ADR-119](../adr/119-user-selected-local-service-configuration.md)。没有新增外部后端、网关、远程脚本或项目账号中转服务；既有 F01–F20 范围和暂停 / 阻塞项保留。

## 下载与安装

从 [v0.66.0 Release](https://github.com/johnnyzhao5619/BiliSofa/releases/tag/v0.66.0) 下载 `BiliSofa-0.66.0-unsigned.wgt`，或含说明、许可与来源记录的 `BiliSofa-0.66.0-download.zip`。软件提交、WGT 大小与 SHA-256、源代码快照及各文件摘要固定在 `release-manifest.json` 和 `SHA256SUMS.txt`，不把来源填写成 e7bc374 相同源码。

按[五步快捷安装](../QUICK_INSTALL.md)使用 Apps2Samsung 自定义 WGT 路径，或用[Samsung 官方工具步骤](../INSTALLATION.md)签名侧载。仍需自己的 Samsung TV 有效证书和 Developer Mode；0.65.1 的哈希不适用于本版。

Application ID 保持 `BiliSofa01.TV`，最低声明 Tizen 9.0；更新保留原 Author。没有执行本候选签名、安装、升级或回退，不将其他安装包的设备结果借给它。

首次安装可从 [Apps2Samsung 稳定版](https://github.com/Apps2Samsung/Apps2Samsung/releases/tag/v2.8.3)下载适合自己电脑的工具，让电视与电脑在同一局域网，按 Samsung 流程打开 Developer Mode，再选择 custom WGT 并载入 `BiliSofa-0.66.0-unsigned.wgt`，使用自己的 Samsung 账号 / 证书完成签名。该第三方路径尚未对本候选独立实测，不能免除签名、Author 或设备兼容要求。

进入电视应用后填写当前支持的网站地址（配置接受 `www.bilibili.com` 或 `bilibili.com`），确认后才进入原账号 / 游客与内容界面。不要在此字段填写 Cookie、token 或 API 密钥；未知网站不会被直接打开。

## 实际检查与未验证

本轮执行 TypeScript 静态检查、依赖 / 全局边界、地址展开迁移摘要检查、Samsung原生重新链接、Web构建和现有打包门禁。最终包另检查运行 JS / WASM 中的业务域名残留、原生配置导出、manifest / 来源和压缩包摘要。

未运行应用测试、浏览器交互、Worker / WASM 运行时、电视遥控 / IME、真实扫码 / 会话、播放 / 投屏或真实账号写入。本地编译成功和静态零地址残留不等于这些行为已通过。
