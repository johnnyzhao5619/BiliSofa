# Security

Do not submit passwords, Samsung signing keys, cookies, access tokens, private device information or unredacted captures in public Issues/PRs.

If a problem involves credential exposure or remote control of a TV, use the repository owner's configured private reporting channel after GitHub publication. A public reporting endpoint has not been configured during local initialization.

Development principles: validate TLS; scope credentials to required domains; use bounded protocol parsing; never execute comment or danmaku content as code; protect account isolation and avoid replaying ambiguous writes.
